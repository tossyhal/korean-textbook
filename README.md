# korean-textbook

日本語話者向けの8週間の韓国語学習Web教材です。全8章・56節の本文・例文・演習・評価を収録しています。節別の収録状況は[教材の制作状況](docs/CONTENT_REPORT.md)、編集・言語・音声の確認状況は[教材の確認状態](docs/CONTENT_STATUS.md)を参照してください。

本文・練習・作文発話・確認テスト・出典メモをタブで切り替えて学べます。発音の説明と聞き分け問題、端末の韓国語音声による読み上げ、自分の録音との比較、2ボル入力の案内と練習があります。進捗や弱点から復習でき、先の節にも進めます。最終節は自動採点24問と作文・発話の自己評価を分けています。未確認の微細な音の対立は採点しません。

登録語彙は辞書形526語で、読む・聞く語彙600〜900語という設計上の目安には未達です。活用形を別語として数えていません。全節の言語と音声は未確認として記録しており、全文の母語話者照合、端末TTSの実聴、録音品質、実IME、iPhone・Windows実機の確認は未実施です。

## 始める

[mise](https://mise.jdx.dev/)を用意し、リポジトリのルートで実行します。Node.jsとpnpmのバージョンはmiseで固定しています。

```sh
mise install --locked
pnpm install --frozen-lockfile
mise run dev
```

表示されたURLの`/korean-textbook/`を開きます。次回からは`mise run dev`で起動できます。学習、入力、音声、バックアップ、ビルドや検査の詳しい手順は[利用と検証の手引き](docs/USAGE.md)を参照してください。タスク一覧は`mise tasks`で確認できます。

進捗はブラウザーの配信元（プロトコル・ホスト・ポート）ごとに保存され、同じ配信元のハッシュ移動では共有されます。端末間の自動同期はなく、ブラウザーのデータ削除で消えるため、設定画面からJSONをバックアップしてください。録音は含まれません。

GitHubリポジトリは作成済みですが、push、CI実行、GitHub Pagesへの公開は未実施です。[配信手順](docs/DEPLOYMENT.md)に準備と未実施事項を記録しています。
