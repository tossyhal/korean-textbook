# korean-textbook

日本語話者向けの8週間の韓国語学習Web教材です。全8章・56節の本文・例文・演習・評価を収録しています。節別の収録状況は[教材の制作状況](docs/CONTENT_REPORT.md)、編集・言語・音声の確認状況は[教材の確認状態](docs/CONTENT_STATUS.md)を参照してください。

各節は本文・練習・実践・確認テストの順に学べます。全56節の説明を補強し、章ごとの独立した編集レビューを通過しています。詳しくは[説明の改訂](docs/READABILITY.md)を参照してください。確認テストの末尾では、条件を満たせば完了して次の節へ進み、満たさない場合は未実施を残して終了できます。単語帳と文法は別画面で参照できます。発音の説明と聞き分け問題、端末の韓国語音声による読み上げ、自分の録音との比較、2ボル入力の案内と練習があります。進捗や弱点から復習でき、先の節にも進めます。最終節は自動採点24問と作文・発話の自己評価を分けています。未確認の微細な音の対立は採点しません。

教材の登録語彙は辞書形526語（531 ID）で、読む・聞く語彙600〜900語という設計上の目安には未達です。単語帳は教材の531項目と教材外の318項目を合わせた849項目で、異なり語数ではありません。活用形を別語として数えていません。順位付き736項目、未照合113項目、自作例文18件です。詳細は[学習動線と単語帳](docs/GUIDED_LEARNING.md)を参照してください。全節の言語と音声は未確認として記録しており、全文の母語話者照合、端末TTSの実聴、録音品質、実IME、iPhone・Windows実機の確認は未実施です。

## 始める

[mise](https://mise.jdx.dev/)を用意し、リポジトリのルートで実行します。Node.jsとpnpmのバージョンはmiseで固定しています。

```sh
mise install --locked
pnpm install --frozen-lockfile
mise run dev
```

表示されたURLの`/korean-textbook/`を開きます。次回からは`mise run dev`で起動できます。学習、入力、音声、バックアップ、ビルドや検査の詳しい手順は[利用と検証の手引き](docs/USAGE.md)を参照してください。タスク一覧は`mise tasks`で確認できます。

進捗はブラウザーの配信元（プロトコル・ホスト・ポート）ごとに保存され、同じ配信元のハッシュ移動では共有されます。端末間の自動同期はなく、ブラウザーのデータ削除で消えるため、ホームの「データ管理」からJSONをバックアップしてください。録音は含まれません。

GitHubリポジトリは作成済みですが、push、CI実行、GitHub Pagesへの公開は未実施です。[配信手順](docs/DEPLOYMENT.md)に準備と未実施事項を記録しています。
