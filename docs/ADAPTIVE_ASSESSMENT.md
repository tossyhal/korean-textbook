# 診断・復習・結果

先取り診断は第1週の文字、入力、基本文を対象とする独立した15問。各5問の初回自力正答8割を独自の目安とし、文字と入力が基準未満なら第1〜3課、基本文が基準未満なら第4〜6課、それ以外は第7課を提案する。解答閲覧後の回答は初回自力正答に含めず、提案は課のロックや公式認定ではない。聴解は診断に含まれず未実施。診断問題は独自作成で第三者による言語照合と音声確認は未実施。

誤答は問題IDとタグを復習へ登録する。復習はローカル日付で1日20件を上限とし、閲覧・自己評価を履歴に保存する。閲覧後に再読み込みや日付変更をしても自己想起として記録できない。予定日は回答したローカル日付から算出する。旧進捗には空の履歴を補完する。

結果は収録課の出口テストを技能別に集計し、自己評価を固定採点と分ける。期限到来の語彙・文型・問題から関連課を提案し、第55課と第56課が追加されたときはそれぞれ結果・復習案へのリンクを表示する。未実施の技能は未実施として扱う。
