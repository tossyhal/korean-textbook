# 評価の受け入れ基準

## 問題の設計

- 各到達目標を問題または自己評価へ対応付ける。練習・出口・週末で同一文を流用しない。
- 同じ技能だけで8割を超えないよう、読解/入力/聴解を配分。発話・作文は別指標。
- 学習済み語彙・文法、丸ごと表現、新出を区別し、未習表現が採点を左右しない。
- 選択肢は不自然なダミーを並べず、典型的な誤解を表す。選択肢別の解説が理想。
- 固定解に複数の自然な回答があり得る場合、許容解に含めるか問題文を限定する。
- 語順/分かち書きが評価対象の場合は空白を消さない。NFC正規化は行う。
- 自由文・自由発話は正誤自動採点しない。模範例と3〜5項目の具体的な自己評価。

## 実行状態

- 初見の回答、再挑戦、解答閲覧後、未回答、音声不可を区別する。
- 全体の点数だけでなく、実施数と未実施数、技能別の分子/分母を示す。
- 解答を先に見た問題は自力正答としない。再挑戦で初回結果を書き換えない。
- 確認済み音声を要する問題で音声が未確認の場合、問題は利用不可・未実施として残し、正答に数えない。day43/44の該当問題は節の完了条件から除外するが、それ以外の未実施問題や未確認の自己評価は完了を妨げる。節の完了は全問正答や成績認定を意味しない。
- 完了は滞在時間や正解表示だけで自動判定しない。未実施を残した場合はその事実を表示。
- 8割は独自の目安。低得点でも課をロックしない。

## 結果と復習

- 正誤に加え、なぜその形か、よくある誤り、該当本文へのリンクを示す。
- 誤答は語彙/文法/技能タグで復習へ登録。解答後に理解したものも復習対象にできる。
- 復習では自力想起と解答を見た理解を別に記録し、失敗を次の予定へ反映。
- 最終評価では読む/聞く/書く/話すを別々に報告し、未実施は未実施のまま。

## 必須の自動・ブラウザ検証

固定解の許容表記/空白/句読点、IME中の採点防止、複数選択肢、初回保持、解答閲覧後、未実施、保存再開、誤答復習、日付変更、破損バックアップ拒否、出典と参照の欠落検出。
