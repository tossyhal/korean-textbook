# 画面設計

日本語話者が長い教材を読み、音を聞き、入力するための教科書画面。装飾より本文と操作の可読性を優先する。見出し上の装飾的な小見出しや英語の副ラベルは置かない。

## 比較と採用

OpenPencilで第1課の文字の組み立てを題材に、PC幅1280pxと幅390pxの案を作成した。画像はレイアウト検討用であり、教材本文や音声の確認状況を示すものではない。

- A「教科書型」: PCでは左に課内目次、右に本文を置く。長い課でも現在地と移動先を確認しやすい。モバイルでは目次を収納し、本文を1列にする。
- B「ノート型」: 中央1列で学習順を強調する。見通しは静かだが、長い課で離れた節に戻る手段が画面上に見えにくい。

Aを採用する。課ごとの教材が長く、参照や弱点への往復が必要なため、PCの目次が有用。Bの余白の取り方も参考にし、見出しや本文をカードで囲わない。文字の組み立て例だけを淡い背景でまとめ、字母と音節の関係を大きく見せる。モックの目次は概念例であり、実際のセクション名は教材データに合わせる。

## 色

| 用途 | 色 |
| --- | --- |
| 本文 | `#182A32` |
| 補助テキスト | `#52656D` |
| 枠線・区切り | `#CCDADD` |
| 背景 | `#FFFFFF` |
| 補助背景 | `#F2F6F6` |
| 操作・選択 | `#176A72` |
| 学習例の背景 | `#E4F2F1` |

状態は色だけで区別せず、「正解」「もう一度確認」などの文言と解説を併記する。無効、読み込み、音声利用不可、保存失敗は理由と次の操作を示す。フォーカスは背景と区別できる輪郭を明示する。

## 文字と余白

本文は日本語と韓国語の双方を表示できるシステムのサンセリフ体を使う。日本語は`system-ui`、韓国語は`lang="ko"`に応じたシステムフォントを優先し、端末にある適切なCJKフォントへフォールバックする。本文は16px以上、行間1.7前後。韓国語の字母・音節の例は28〜32pxを基準に、似た文字の形を判別できる大きさにする。見出しはページタイトル28〜32px、節見出し20〜22px。本文幅は最大680〜720px程度とし、項目間16px、節間32〜48pxを目安とする。

モック画像はOpenPencilのCJKフォント指定で書き出した。フォントや改行は実ブラウザで再確認する。

## 配置と操作

PCでは本文の左に課内目次を置く。本文は読める幅に制限し、音声・停止・答え合わせなどは対象のすぐ近くに配置する。練習と確認テストを見出しと操作で明確に区別し、初回・再挑戦・答え閲覧の状態を言葉で示す。入力欄と明示的な答え合わせボタンを組にし、変換中に判定しない。音声は利用可能性と確認状況を明示し、未確認の音を確認済みとして扱わない。

操作対象は44px程度以上を目安にし、キーボードで操作可能にする。hoverだけに情報を隠さず、動きは控えめにし、reduced motionを尊重する。

## レスポンシブ

狭い画面では1列とし、左右に20px前後の余白を確保する。課内目次は開閉できる導線にまとめ、読書や入力を覆う固定バーは置かない。長い文や選択肢は折り返し、入力欄・ボタンは画面内に収める。ソフトウェアキーボード表示時も入力欄と答え合わせに到達できるようにする。390px幅とPC幅を実ブラウザで確認し、拡大表示や小さい画面でも横スクロールを生じさせない。
