# 学習動線と単語帳

各節は本文・練習・実践・確認テストの4段階で、左目次から移動できる。確認テストは練習と別問題。不正解では答えと解説を伏せ、答えを見る前の再挑戦と閲覧後の回答を区別する。末尾の主ボタンは、確認テストと実践の自己評価などの条件を満たすと完了して次へ進む。条件を満たさない場合は未実施を残して終了し、目次にも別の状態として表示する。未実施の回答やチェックは変えず、未実施を技能実績に加算しない。保存上は`partiallyFinishedLessons`で完全完了と区別し、後から再開できる。第7章第1・2節は重要な音声が未確認のため現在完全完了できず、この部分終了を利用できる。完了は成績認定ではない。目次から任意の節を開くこともできる。

実践は全56節にあり、文字入力3節、発話6節、作文47節に分かれる。自由に作る文章や発話は自己評価であり、自動採点しない。自己確認は模範例の外にある。結果では入力を別に数え、発話には発音練習の自己評価も含む。発音能力の認定ではない。課題の対応と設計の確認範囲は[実践課題の設計確認](reviews/activity-design.md)を参照する。

単語帳は教材の531 IDと教材外318項目を合わせた849項目で、異なり語数ではない。教材内の辞書形は526語であり、読む・聞く語彙600〜900語の設計目安には未達である。単語帳には独自に作成した例文を18件収録する。検索、品詞の絞り込み、意味を隠す操作、40項目ずつの表示、韓国語の音声再生、復習への追加ができる。節内の語彙も韓国語を押して再生できる。文法は別表示に切り替え、同じ節の実際の例文を再生できる。

736項目に頻度順位があり、113項目は順位未照合として末尾に置く。順位は国立国語研究院の2002年の使用頻度調査に基づく2003年公開の学習用語彙一覧によるもので、現在の会話や学習優先度を普遍的に示すものではない。順位未照合は低頻度を意味しない。照合条件と出典は[単語帳の出典と照合](research/wordbook-sources.md)に記録する。

韓国語の音声は利用可能な端末の合成音声を自動選択し、再生オプションで速度や繰り返しを変更できる。発音画面の折りたたまれた「音声が出ないとき」から、利用可能な声を選択・試聴できる。設定ページは撤去した。旧来の保存データのメモや出典位置は互換性のため保持する。全文の母語話者照合、端末音声の実聴、録音品質、実IME、iPhone・Windows実機の確認は未実施。単語帳の語義対応や教材外の訳も全文照合されていない。最新の自動検証は[検証記録](VERIFICATION-guided-wordbook.md)を参照し、過去の検証結果は今回の変更の成功を意味しない。
