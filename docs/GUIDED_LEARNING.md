# 学習動線と単語帳

各節は本文・練習・実践・確認テストの4段階で、開閉できる学習ナビゲーションから移動でき、開閉状態はブラウザーに保存され、開閉ボタンには常に到達できる。ナビゲーションは本文を覆わない。確認テストは練習と別問題。不正解では答えと解説を伏せ、答えを見る前の再挑戦と閲覧後の回答を区別する。末尾の主ボタンは、確認テストと実践の自己評価などの条件を満たすと完了して次へ進む。条件を満たさない場合は未実施を残して終了し、目次にも別の状態として表示する。未実施の回答やチェックは変えず、未実施を技能実績に加算しない。保存上は`partiallyFinishedLessons`で完全完了と区別し、後から再開できる。第7章第1・2節の未確認重要音声は未実施・利用不可に残し、完了の必須条件から除く。他の未実施問題と自己評価は完了を妨げる。第7章第5節の別音声練習も任意で、回答や実施記録を捏造しない。完了は成績認定ではない。目次から任意の節を開くこともできる。

実践は全56節にあり、文字入力3節、発話6節、作文47節に分かれる。自由に作る文章や発話は自己評価であり、自動採点しない。自己確認は模範例の外にある。各節のフィードバックと自己評価、弱点からの復習は維持する。独立した学習結果画面は撤去し、旧`#/results`は復習画面を開く。履歴は保存データとバックアップに保持する。発音能力の認定ではない。課題の対応と設計の確認範囲は[実践課題の設計確認](reviews/activity-design.md)を参照する。

単語帳は教材の531 IDと教材外322項目を合わせた853項目で、異なり語数ではない。教材内の辞書形は526語であり、読む・聞く語彙600〜900語の設計目安には未達である。単語帳には独自に作成した例文を18件収録する。検索、品詞の絞り込み、意味を隠す操作、40項目ずつの表示、韓国語の音声再生、復習への追加ができる。節内の本文や語彙なども韓国語を押して再生でき、再生中に同じ箇所を押すと停止する。文中では通常の段落の行間を保ち、独立した操作は44pxを目安とする。字母単体は名前を読み、音の練習の見本は明示された音節や単語を読む。文法は別表示に切り替え、同じ節の実際の例文を再生できる。

736項目に頻度順位があり、117項目は順位未照合として末尾に置く。順位は国立国語研究院の2002年の使用頻度調査に基づく2003年公開の学習用語彙一覧によるもので、現在の会話や学習優先度を普遍的に示すものではない。順位未照合は低頻度を意味しない。照合条件と出典は[単語帳の出典と照合](research/wordbook-sources.md)に記録する。

韓国語の音声は利用可能な端末の合成音声を自動選択し、再生オプションで速度や繰り返しを変更できる。発音画面の折りたたまれた「音声が出ないとき」から、利用可能な声を選択・試聴できる。聞き取り問題では答えを伏せたまま再生できる。再生成功や音質の注意を繰り返さず、利用不可やエラーは表示する。設定ページは撤去した。旧来の保存データのメモや出典位置は互換性のため保持する。全文の母語話者照合、端末音声の実聴、録音品質、実IME、iPhone・Windows実機の確認は未実施。単語帳の語義対応や教材外の訳も全文照合されていない。今回の検証は[検証記録](VERIFICATION-external-review.md)を参照する。[以前の検証記録](VERIFICATION-guided-wordbook.md)は今回の変更の成功を意味しない。
