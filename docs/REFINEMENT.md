# 教材と画面の改訂

元の仕様履歴は`korean_8week_codex_prompt.md`を参照する。この文書は現在の改訂内容と残る確認を記録する。

- 全8章・各7節とし、旧day1〜56の内部IDを維持する。目次から前提条件なしで各節を開け、状態を図形と文字で示す。
- 先取り診断を撤去し、旧URLは目次に移す。既存の進捗JSONとの互換性を維持する。
- 左目次を本文・練習・実践・確認テストの4段階とする。確認テスト末尾は条件を満たせば完了して次へ、満たさなければ未実施を残して終了する。回答や自己確認を捏造せず、目次で区別する。day43/44の未確認重要音声は未実施・利用不可として残し、完了に必須の問題から除く。他の未実施問題や自己評価は完了を妨げる。day47の別音声練習も任意で、実施記録を捏造しない。利用者向けの「想起」は「復習」とする。
- 不正解時は答えと解説を伏せて再挑戦できる。各節のフィードバック、自己評価、弱点からの復習を維持する。独立した学習結果画面とナビゲーションは撤去し、旧`#/results`は復習画面へ移す。履歴と保存・バックアップの互換性は維持する。ホームの60・90・120分の選択も撤去した。これは学習計画の助言であり、別々のカリキュラムではなかった。
- 字母と音節の音声ガイドを用意し、韓国語の合成音声を自動選択する。発音画面の折りたたみで利用可能な声を選択・試聴できる。節内語彙と文法一覧の同じ節の例文も再生できる。設定ページは撤去し、旧データのメモ・出典位置は互換性のため保持する。選択肢の順番は安定したシャッフルを使う。
- 単語帳には教材内531項目と教材外322項目を収録する。計853項目は異なり語数ではなく、順位付き736項目、未照合117項目、自作例文18件。頻度順位の出典と照合範囲は[出典記録](research/wordbook-sources.md)を参照。
- 過去の改訂では全56節をSolとOpus5.5で独立レビューし、修正後の指摘範囲を別のSolセッションで再確認した。今回の読みやすさ改訂の受け入れを意味しない。現在の章別状況は[説明の改訂](READABILITY.md)を参照する。
- 学習ナビゲーションは本文上部のボタンで開閉でき、状態を保存する。本文などの韓国語は押して再生し、同じ箇所を再度押すと停止する。字母単体は名前、音の練習の見本は明示された音節や単語を読む。文中の操作は通常の段落の行間を保ち、独立した操作は44pxを目安とする。聞き取り問題では答えを伏せたまま再生できる。再生成功や音質の注意の繰り返しを整理し、利用不可やエラーは表示する。全56節の未確認状態はデータと文書に保持する。

教材を固定して[制作状況](CONTENT_REPORT.md)を再生成した。辞書形526語で、600〜900語の設計目安には未達。旧版のレビューと[最終検証](VERIFICATION-final.md)は当時の記録であり、改訂版の成功を示さない。以前の改訂版の動作検証は[検証記録](VERIFICATION-refinement.md)を参照。以前の動線・単語帳の検証は[検証記録](VERIFICATION-guided-wordbook.md)を参照。今回の検証は[検証記録](VERIFICATION-external-review.md)に記録する。

一次資料の個別事項の照合、ソフトウェアの自動テスト、端末音声の実聴、実機確認、全文の母語話者照合は別の確認である。実聴、実機、全文の母語話者照合は未実施。Pagesの初回配信と動作確認は[配信検証記録](VERIFICATION-pages.md)を参照。有料APIと外部アカウント作成は行わない。

独立レビューの指摘と採否は[対応記録](reviews/guided-resolution.md)にまとめる。

外部レビューへの対応範囲と残る確認は[対応記録](EXTERNAL_REVIEW.md)を参照する。文法復習は各項目の教材に即した設問であり、各文法の全用法を網羅するものではない。
