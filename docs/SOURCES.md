# 単語帳の出典と照合

- 国立国語研究院『한국어 학습용 어휘 목록』（2003年5月、[公式配布ページ](https://www.korean.go.kr/front/etcData/etcDataView.do?etc_seq=70&mn_id=46&pageIndex=26)）。掲載5,965語のうち第1段階は982語。ページは五十音に相当する韓国語順で並べた一覧と説明している。
- 一覧の「순위」列は同院『현대 국어 사용 빈도 조사』（2002年）の頻度順位。並びの通し番号ではない。順位は2002年当時の調査に基づき、現代の会話における普遍的な順位や学習優先順位ではない。
- 公式ページには公共ヌリ第1類型、具体的な出典表示を条件に利用可能と明記されている。単語帳の順位はこの資料に由来し、短い日本語訳は教材用に作成した。元資料の풀이や例文は転記していない。
- 初版では辞書形と品詞が一致し、その組に原資料の同音異義語が複数ない場合に順位を付けた。追加照合では下記の個別の語義を確認できた同形異義語にも順位を付けた。完全な語義照合ではないため、同形同品詞に複数項目がある場合や対応しない表現には順位を付けない。順位なしは低頻度を意味しない。
- 原資料に同形同品詞の項目が一つしかなくても、教材の語義と一致するとは限らない。지각「遅刻」と베다「枕などを当てる」は、原資料のそれぞれ「知覚」（5284位）と「切る」（3750位）に対応しないため順位を付けない。今後の照合でも表記と品詞に加えて語義を確認し、一致を確認できない場合は順位を付けない。
- 教材内のIDを維持し、教材外の語は別IDを付けた。教材外の語の選択と訳、順位の語義対応は母語話者による全文照合を受けていない。端末音声の実聴も未実施。

## 追加の個別照合

- 基本語14項目を追加し、原資料の該当項目を確認した。것01（1位）、하다01動詞（2位）、되다01「大人になる」（5位）、나03（8位）、우리03（13位）、년02（26位）、때01「時間」（19位）、같다（22位）、잘02（68位）、말01「言葉」（28位）、말하다（32位）、생각하다（58位）、때문（31位）、네03感動詞（357位）。
- 教材語の먹다02「食べる」（70位）、쓰다01「書く」（169位）、밤01「夜」（276位）、타다02「乗る」（260位）を語義で対応付けた。일05数詞「一」（7600位）は日付の数字にも使うため維持し、일07依存名詞「一日」（41位）とは区別した。
- 教材外の감다は「巻く」감다03（4036位）と「髪を洗う」に分離し、後者は対応する原資料の項目を確認できないため順位なしとした。既存のIDは「巻く」に維持した。
- その他の順位なし項目も語義を確認し、가구04「家具」（7434位）、검사03「検査」（1512位）、공기06「空気」（1433位）、달리다04「走る」（867位）、들다04「持つ」（130位）、따르다01「従う」（51位）、맞다01「合う」（378位）、묻다03「尋ねる」（289位）、바람01「風」（478位）、사고12「事故」（691位）、새03「鳥」（1089位）、이해06「理解」（930位）、지우다01「消す」（2812位）を対応付けた。これら以外の既存順位について全文の語義照合は未実施。

## 表示構成の参考

多楽園の[2000 Essential Korean Words](https://koreanbooks.darakwon.co.kr/detail.asp?bookid=8&category=6&lang=1)は、テーマごとの語、意味、使用文脈、関連表現、音声を組み合わせている。本アプリでは韓国語と意味を同じ行で見比べ、意味を隠して確認できる構成と、語を押す再生操作を参考にした。教材外の基本語も含め、表示順は上記の頻度資料に従う。商用教材の訳、例文、音声を転用していない。テーマ別分類と全項目の例文は未収録。
