# 学習画面の接続

アプリはハッシュルーティングを使い、発音リファレンスとキーボード練習を`AudioProvider`内に置く。キーボードの下書きキーは`REFERENCE_API.md`を参照。

課内位置の保存・バックアップには`objectives`、`recall`、`section-N`、`vocabulary`、`examples`、`dialogue`、`exercises`、`production`、`exit`、`sources`などを使う。旧出典位置を含む互換性のための値があり、すべてが現在の画面上の位置を意味するわけではない。回答下書きは問題ID、作文下書きと旧メモは課IDで保存する。メモは現在の画面には表示しない。`productionChecks`は課IDごとの自己確認項目の真偽値配列で、旧データには空オブジェクトを補完する。バックアップは教材IDと入力練習の有限キーを検証する。ホームの時間選択は撤去済みで、旧教材の時間別説明はデータに保持する。
