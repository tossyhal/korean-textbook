# 文字の組立表示と入力案内

第1〜3課に字母を選んで音節を見る組立表示を追加した。第1課は基本子音14字と基本母音10字、第2課から濃音と複合母音、第3課から代表的な終声7種を選べる。終声なしも選べる。音声は組み立てた音節のみ任意で再生する。初声と終声のㅇの違いを説明し、音声の内容は未確認と表示する。入力や進捗保存の仕組みは変更していない。

合成の計算は[Unicode Standard 17.0の3.12.3 Hangul Syllable Composition](https://www.unicode.org/versions/Unicode17.0.0/UnicodeStandard-17.0.pdf)に基づく。参照画面の韓国語の見出しに言語指定を付け、iPhoneの入力案内には配列上段を見て確認する方法を追記した。配列名や実機手順は未確認。

## 動作と表示の確認

- Vitestで基本音節、濃音・複合母音、終声の合成を確認。
- Playwrightで第1〜3課の選択肢と組立結果を確認。型検査、lint、変更ファイルの書式検査を通過。
- agent-browserのChromiumで1280pxと390pxの表示を確認。390pxで横はみ出しなし。選択欄のラベルとキーボードフォーカスの輪郭を確認。組立表示にアニメーションはない。アクセシビリティの確認はこれらの項目に限り、支援技術での操作確認は未実施。
- Impeccableの機械検査は指摘なし。

## 未確認

教材説明の言語的照合、合成音声の発音、iPhoneとWindowsの実機操作、スクリーンリーダーでの読み上げは未確認。Chromiumの表示確認は実機検証を意味しない。
