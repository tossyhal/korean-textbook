# 利用と検証の手引き

## 起動

リポジトリのルートで初回に`mise install --locked`、`pnpm install --frozen-lockfile`を実行します。`mise run dev`で起動し、表示されたURLの`/korean-textbook/`を開きます。終了はCtrl+Cです。通常は`mise run dev`だけで再起動できます。

`mise run build`で型検査とビルドを実行し、`dist/`を生成します。`mise run preview`で生成物をローカル確認できます。表示されたURLの`/korean-textbook/`を開き、Ctrl+Cで終了します。公開手順は[配信準備](DEPLOYMENT.md)を参照してください。GitHub Pagesへの公開は未実施です。

## 学習

目次から章・節を選び、本文・練習・実践・確認テストの順に進みます。左の目次から各段階へ移動できます。確認テストは練習とは別の問題です。末尾の主ボタンは条件を満たすと「完了して次へ」、満たさないと「未実施を残して学習を終えて次へ」になります。目次でも両者を区別し、後から再開できます。未実施の回答やチェックは作られず、技能実績にも加算されません。第7章第1・2節は重要な音声が未確認のため完全完了の条件を満たせず、未実施を残して終了できます。節は自由に開けます。不正解時は答えと解説を伏せて再挑戦でき、「答えを見る」後に表示します。回答の初回、再挑戦、答え閲覧後は区別され、結果画面に初回自力回答と弱点への復習先が表示されます。未実施は0点ではありません。作文・入力・発話は自己評価で、AIによる採点はありません。自己確認は模範例を開かずに使えます。結果では入力を別に数え、発話の自己評価には発音練習も含みます。

目次には学習状況が図形と文字で表示されます。節を開くための前提条件はありません。以前の先取り診断のURLは目次へ移動します。

「単語帳・文法」では単語を検索、品詞で絞り込み、意味を隠して学べます。40項目ずつ表示し、韓国語を押すと利用可能な端末の合成音声を再生します。文法は別表示に切り替え、同じ節の実際の例文を再生できます。各節の語彙も韓国語を押すと再生できます。語彙や文法は手動で復習に追加・解除できます。復習画面では答えを見る前に思い出せたか、見て理解したか、思い出せなかったかを選びます。期限到来分は1日最大20件で、残りは翌日以降に取り組めます。節自体はいつでも開けます。

キーボード画面にiPhoneとWindows 11の韓国語入力の設定と練習があります。OSの画面や配列名は端末で確認してください。iPhone・Windows実機と実際のIMEは未確認です。

## 音声と録音

教材データの`production.model`は表示用の模範例です。作文と発話が異なる場合は、韓国語の発話例だけを`production.speakingModel`に指定します。省略時は`model`を録音比較の手本に使用します。

韓国語の合成音声は端末で利用可能な声を自動選択します。音声ボタンの「再生オプション」から速度や文ごとの再生を選べます。発音画面の「音声が出ないとき」を開くと、利用可能な声の選択・試聴と設定案内を使えます。設定ページはありません。合成音声の発音・音質とOSの設定手順は実機未確認です。

録音比較ではマイクを許可し、録音を停止して手本と聞き比べます。録音は画面のメモリ内に保持され、必要ならダウンロードできます。画面を離れる前に保存してください。録音は送信・自動採点されず、進捗のバックアップにも含まれません。録音にはHTTPSまたはその端末自身のlocalhostが必要です。PCのlocalhostを別端末からLANのHTTPで開いても安全なコンテキストにはなりません。

ロールプレイは自分で発話を進める自己練習です。音声や録音を使えない場合は未実施のまま進めます。複数の合成音声を使う練習も、必要な声が足りない場合は未実施として扱います。

## 進捗とバックアップ

進捗はブラウザーのlocalStorageに、配信元（プロトコル・ホスト・ポート）単位で保存されます。同じ配信元では画面内のハッシュ移動で共有されます。別端末との自動同期はありません。画面に表示しない旧来のメモや出典位置も互換性のため保存データに保持します。ブラウザーのデータ削除などで消えるため、ホームの「データ管理」にある「バックアップを書き出す」でJSONを保存してください。復元は「バックアップを選ぶ」で内容を確認してから適用します。適用すると現在の進捗を置き換えます。

## 開発時の検証

```sh
mise run format
mise run format:check
mise run lint
mise run typecheck
mise run test
mise run content:check
mise run content:report
mise run build
```

`format`はファイルを書き換えます。`content:check`は全56節を要求する厳格検査で、教材が不足する制作途中は失敗します。収録済みの範囲だけを確認するには`pnpm run content:check -- --partial`を使います。完成判定の代わりにはなりません。`content:report`は[制作状況](CONTENT_REPORT.md)を再生成します。

Chromiumのブラウザーテストはブラウザーと必要なホストライブラリを用意して実行します。

```sh
pnpm exec playwright install --with-deps chromium
mise run test:browser
```

Desktop WebKitは同様にホストのライブラリが必要です。

```sh
pnpm exec playwright install --with-deps webkit
pnpm exec playwright test --config playwright.webkit.config.ts
```

ホストへの依存導入ができないLinuxでは、依存インストール済みのリポジトリで別ターミナルから`mise run dev -- --host 127.0.0.1`を起動し、公式イメージを使えます。

```sh
docker run --rm --network host --user "$(id -u):$(id -g)" -v "$PWD:/work" -w /work mcr.microsoft.com/playwright:v1.65.0-noble node node_modules/@playwright/test/cli.js test --config playwright.webkit.config.ts
```

このDocker例はLinuxのホストネットワークと起動中の127.0.0.1:5173を前提とします。Desktop WebKitはiPhone実機やiOS Safariの代わりではありません。ブラウザーテストの音声・録音はモックで、実音声・実マイクの品質は確認しません。教材の言語全文の専門家による照合、実音声、iPhone・Windows実機の確認状況は[教材の確認状態](CONTENT_STATUS.md)と各検証記録を参照してください。
