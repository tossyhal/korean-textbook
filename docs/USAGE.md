# 利用と検証の手引き

## 教材を開く

[公開中の教材](https://tossyhal.github.io/korean-textbook/)をブラウザーで開きます。進捗はそのブラウザーに保存されます。

## ローカルで起動

リポジトリのルートで初回に`mise install --locked`、`pnpm install --frozen-lockfile`を実行します。`mise run dev`で起動し、表示されたURLの`/korean-textbook/`を開きます。終了はCtrl+Cです。通常は`mise run dev`だけで再起動できます。

`mise run build`で型検査とビルドを実行し、`dist/`を生成します。`mise run preview`で生成物をローカル確認できます。表示されたURLの`/korean-textbook/`を開き、Ctrl+Cで終了します。公開手順は[保守の手引き](MAINTENANCE.md)を参照してください。

## 学習

目次から章・節を選び、本文・練習・実践・確認テストの順に進みます。学習ナビゲーションから各段階へ移動できます。本文上部のボタンで開閉でき、開閉状態はブラウザーに保存され、開閉ボタンには常に到達できます。ナビゲーションは本文を覆いません。確認テストは練習とは別の問題です。末尾の主ボタンは条件を満たすと「完了して次へ」、満たさないと「未実施を残して学習を終えて次へ」になります。目次でも両者を区別し、後から再開できます。未実施の回答やチェックは作られず、技能実績にも加算されません。第7章第1・2節の未確認の重要音声は未実施・利用不可のまま残り、完了の必須条件には含まれません。その他の未実施問題や自己評価は完了を妨げます。第7章第5節の別音声練習も任意です。節は自由に開けます。不正解時は答えと解説を伏せて再挑戦でき、「答えを見る」後に表示します。回答の初回、再挑戦、答え閲覧後は区別され、各節の確認テストで回答へのフィードバックと弱点への復習先を確認できます。未実施は0点ではありません。作文・入力・発話は自己評価で、AIによる採点はありません。自己確認は模範例を開かずに使えます。独立した学習結果画面はなく、以前の`#/results`は復習画面を開きます。過去の学習履歴は保存データとバックアップに保持されます。

目次には学習状況が図形と文字で表示されます。節を開くための前提条件はありません。以前の先取り診断のURLは目次へ移動します。

「単語帳・文法」では単語を検索、品詞で絞り込み、意味を隠して学べます。40項目ずつ表示し、韓国語を押すと利用可能な端末の合成音声を再生します。文法は別表示に切り替え、同じ節の実際の例文を再生できます。各節の本文や語彙などの韓国語も押すと再生でき、再生中に同じ箇所を押すと停止します。字母だけの表示は字母の名前を読み、文中では通常の行間のまま操作できます。独立した再生操作は44pxを目安にしています。発音練習の音声見本は明示された音節や単語を読みます。語彙や文法は手動で復習に追加・解除できます。復習画面では答えを見る前に思い出せたか、見て理解したか、思い出せなかったかを選びます。期限到来分は1日最大20件で、残りは翌日以降に取り組めます。節自体はいつでも開けます。

キーボード画面にiPhoneとWindows 11の韓国語入力の設定と練習があります。OSの画面や配列名は端末で確認してください。iPhone・Windows実機と実際のIMEは未確認です。

## 音声と録音

韓国語の合成音声は端末で利用可能な声を自動選択します。音声ボタンの「再生オプション」から速度や文ごとの再生を選べます。発音画面の「音声が出ないとき」を開くと、利用可能な声の選択・試聴と設定案内を使えます。設定ページはありません。聞き取り問題では答えを伏せたまま再生ボタンを使えます。再生成功や音質の注意を毎回繰り返さず、利用不可やエラーは表示します。合成音声の発音・音質とOSの設定手順は実機未確認です。

録音比較ではマイクを許可し、録音を停止して手本と聞き比べます。録音は画面のメモリ内に保持され、必要ならダウンロードできます。画面を離れる前に保存してください。録音は送信・自動採点されず、進捗のバックアップにも含まれません。録音にはHTTPSまたはその端末自身のlocalhostが必要です。PCのlocalhostを別端末からLANのHTTPで開いても安全なコンテキストにはなりません。

ロールプレイは自分で発話を進める自己練習です。音声や録音を使えない場合は未実施のまま進めます。複数の合成音声を使う練習も、必要な声が足りない場合は未実施として扱います。

## 進捗とバックアップ

進捗はブラウザーのlocalStorageに、配信元（プロトコル・ホスト・ポート）単位で保存されます。同じ配信元では画面内のハッシュ移動で共有されます。別端末との自動同期はありません。画面に表示しない旧来のメモや出典位置も互換性のため保存データに保持します。ブラウザーのデータ削除などで消えるため、ホームの「データ管理」にある「バックアップを書き出す」でJSONを保存してください。復元は「バックアップを選ぶ」で内容を確認してから適用します。適用すると現在の進捗を置き換えます。
