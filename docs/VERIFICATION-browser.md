## 第1週時点の記録

2026-11-12に開発サーバーの`/korean-textbook/`をChromiumヘッドレスで確認した。`pnpm exec playwright install chromium`の後、`mise run test:browser`で実行する。開発サーバーが動作中なら再利用し、そうでなければ自動起動する。各テストは独立したブラウザーコンテキストを使う。

`pnpm run test:browser`は14件成功。第1課の回答と保存、初回誤答履歴の維持、解答閲覧後の回答、IME変換中の採点防止と確定後の編集、作文・自己評価、JSON書き出しと取消・適用・破損拒否、復習日付と先取り、390px・1280pxの横幅を確認した。採点時に答えと解説を表示するため、その後の回答は答え閲覧後として記録される。未閲覧の再挑戦の判定は単体テストで扱う。

録音の許可・拒否・非対応、WebM・MP4形式、トラック停止と遅延許可後の離脱、遅延したvoiceschanged、声なし、再生エラー、停止連打と画面遷移はブラウザーAPIをモックして確認した。これは実音声や実マイクの品質を検証しない。

実機のiPhone・Windows、実際のIME、実マイクや音声の品質、Chromium以外のブラウザーは未確認。言語内容の照合は別記録とする。
