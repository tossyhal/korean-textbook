# 実装計画

> 過去の計画・検証時点の記録です。現在の仕様や確認状態は[文書案内](../README.md)を参照してください。

## 合意事項

React + TypeScript + Viteの静的サイト。GitHub Pages向けbase pathとハッシュルーティング。端末内保存とJSON移行。シンプルなデザイン、セカンダリラベルなし。公開操作なし。

## 受け入れ基準

- 全56課は本文、例文、会話、問題、許容解、解説、課題、出口評価、前提、出典を持つ。
- 通常課は例文6〜10、演習12以上、出口5程度。文字・試験課は目的に応じて構成。
- 初見評価、既出復習、自己評価、未実施を分離。答え閲覧後は自力正答として記録しない。
- 音声確認状況、言語資料照合、ソフトウェアテストを独立して記録。
- 第1週完成・レビュー・ブラウザ確認後に、週2〜8を順番に制作・検証。
- 起動、型検査、教材検査、ユニット、ブラウザ、lint/format、buildの実行結果を残す。
