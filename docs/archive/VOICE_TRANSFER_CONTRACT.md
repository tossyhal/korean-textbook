# 別の合成音声による聞き取り練習

> 過去の計画・検証時点の記録です。現在の仕様や確認状態は[文書案内](../README.md)を参照してください。

教材の`voiceTransfer`は任意。`sameSentence`は手本と別の合成音声の両方で再生し、`newSentence`は別の合成音声で再生する。それぞれ韓国語の`korean`と日本語訳の`japanese`を必須とする。例はテスト専用の`tests/browser/fixtures/voice-transfer.tsx`を参照。第47課への教材投入と言語的照合は別途必要。

利用者が異なるvoiceURIを明示選択し、3回の再生が終了した場合のみ画面上に再生終了を表示する。中断・エラーは未実施。原文の照合と復唱を自己確認すると選択した声のURIと日時を進捗に保存し、バックアップにも含める。録音は保存せず、得点や発音の認定はしない。この記録は対応する課の完了条件となる。声が不足する場合も他の学習は続行できる。異なるURIは独立した話者を保証しない。端末の合成音声は内容・発音未確認であり、確認済み音声を必要とする細音対立の評価には使用しない。
