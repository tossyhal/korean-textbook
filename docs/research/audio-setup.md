# 音声設定の調査

2026-11-12に公式資料を確認。Appleの[声の設定](https://support.apple.com/ja-jp/111798)は旧名称「読み上げコンテンツ」と声の選択を説明する。[iPhoneユーザガイド](https://support.apple.com/ja-jp/guide/iphone/-iph96b214f0/ios)は今回の直接取得で429となり、親セッションが検索本文を確認した現名称「リーダーと読み上げ」を記載した。Microsoftの[音声合成言語のインストール](https://support.microsoft.com/ja-jp/education/learning-accelerators/download-languages-and-voices-for-immersive-reader-read-mode-and-read-aloud)はWindows 10/11の言語設定とテキスト読み上げ機能を説明する。

これらはOSの設定方法であり、追加した声がWeb Speech APIへ公開されることの保証ではない。端末の設定、ブラウザー再起動後の再検出と試聴、音量・出力先の確認を案内する。iPhone・Windows実機、実音声は未確認。
