# 初学者の前提：照合と編集方針

確認日：2026-11-12。本文への反映は音声の実聴や母語話者校閲を意味しない。

- [国立国語院「標準発音法」の設問解説](https://m.korean.go.kr/nkview/nknews/199906/11_8.htm)：設問6は用言語幹末のㄺがㄱの前で[ㄹ]になること、設問9は二重パッチムが母音始まりの語尾に続くと後ろの子音を次音節へ移し、その子音がㅅなら濃音になることを説明する。없어요[업써요]、읽어요[일거요]、읽고[일꼬]は該当条件を用いた教材例。原綴りと発音表記を区別し、一覧の暗記を求めず使用前に扱う。
- [国立国語院学習辞典：과](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=78624&nation=eng)：パッチムのある名詞に付き、名詞の列挙や同行者を表す用法、対応する와と同義の하고を確認。
- [国立国語院学習辞典：제](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=75826)：話し手がへりくだる저の所有形저의の縮約形제を確認。

編集では、二重パッチムを없어요・읽어요・읽고の初使用前に分けて導入する。形容詞の辞書形と丁寧な述語を理由の接続形より先に説明する。指示語、所有、名詞の列挙と同行者は使用前に分散し、短い意味確認を付ける。音声は端末の合成音声のまま未確認とする。

- [国立国語院：日付の分かち書き](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&qna_seq=303543)：月日を併記する際の数と単位の分かち書きと、続け書きの許容を確認。月名単独は続ける。オープンレビューの疑義を照合し、第11課の原則表記を維持した。
- [国立国語院：에서](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=261&pageIndex=1&qna_seq=335233)：出発点を表す格助詞の用法を確認。第18課は場所の移動起点に에서を明示し、부터の場所用法を非文と断定しない。
