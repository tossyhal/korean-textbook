# 後半教材の初心者向け見直し

確認日：2026-11-12。対象は第29〜56課の初心者レビュー（SOL-04、05、08〜11）と同系列の問題。第1〜28課の前提導入は別担当。第31課の옆は既存IDを第32課から前倒しし、同じ語彙を再参照する。제＝저의と指示語は前半で導入する方針に合わせた。

- [国立国語院オンライン相談：하여요と해요](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=306903)：하여요とその縮約形해요の関係を確認。固定入力の指示が縮約を限定しない場合に両形を受け入れる。
- [国立国語院の初級韓国語指導資料](https://www.korean.go.kr/common/download.do?book_seq=295&c_file_name=fbe8dc8b-5b54-46d0-96cb-229db3f23b4f_0.pdf&downGubun=bookDataView&file_path=bookData&o_file_name=%ED%95%9C%EA%B5%AD%EC%96%B4%EC%A7%84%ED%9D%A5-02-18.pdf)：했어요と하였어요の対応を確認。
- [韓国語基礎辞典：회사](https://krdict.korean.go.kr/m/jpn/searchResultView?ParaWordNo=31668&currentPage=1&exaType=&font_size=12&mainSearchWord=%ED%9A%8C%EC%82%AC&nation=jpn&nationCode=7&proverbType=&searchType=W&sort=&viewType=A&wordMatchFlag=N)：会社の意味と회사에서の用例を確認。
- [韓国語基礎辞典：자주](https://krdict.korean.go.kr/eng/dicMarinerSearch/search?mainSearchWord=%EC%9E%90%EC%A3%BC&nation=eng)：頻度を表す副詞の意味を確認。
- [韓国語基礎辞典：빵](https://krdict.korean.go.kr/eng/dicMarinerSearch/search?mainSearchWord=%EB%B9%B5&nation=eng)：食べ物のパンという名詞の意味を確認。

第46〜49課では操作に関する案内を本文に残し、確認テストは韓国語の情報理解に変更。第56課は読解・聴解・固定入力を各8問に保ち、人数、時刻、価格、外出先の用件、意図からの文型選択を加えた。作文と発話は自己評価を維持する。第34、36、40、41課に既習・中核語の韓国語文脈、意味確認と入替の指示を追加し、認識用の名詞を使用習得済みとは扱わない。

これらは変更範囲の資料照合であり、全教材の母語話者照合ではない。端末音声の実聴、実機・実IME確認は未実施。音声は未確認の合成音声のままである。

独立レビュー追加分：国立国語院の[인분](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=70759&nation=eng)で料理の人数分を数える用例、[로・으로](https://m.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=324214)でㄹ終わりに로を付ける条件を確認した。[ローマ字表記法](https://www.korean.go.kr/kornorms/m/m_regltn.do?regltn_code=0004)の例で같이[가치]・좋고[조코]、[韓国語基礎辞典 연락](https://krdict.korean.go.kr/jpn/dicSearch/SearchView?ParaWordNo=14013)で[열락]を確認。平音の有声化は第43課の国立国語院講義資料を参照した。確認日はいずれも2026-11-12。
