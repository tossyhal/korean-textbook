# 本文中の字母の音声

本文中の単独字母は、初声・終声の文脈を推定せず字母名を読み上げる。発音ガイドは別に明示した音節・単語例を使う。

- [国立国語院：ハングル字母の名前](https://www.korean.go.kr/front/mcfaq/mcfaqView.do?mcfaq_seq=5573&mn_id=62)：基本字母、双子音、複合母音の名前を照合した。
- [国立国語院：複合パッチムの呼び方](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=327221)：構成字母の名前を順に読む方法を確認した。

文字列の照合であり、端末ごとの合成音声の実聴や発音品質の確認ではない。
