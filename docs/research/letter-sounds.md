# 字母の音声見本の照合

## 言語的照合

- 2026-11-12、国立国語院の[オンライン相談回答](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=73&pageIndex=1&qna_seq=329918)の標準発音法第14項に関する説明を確認。終声ㅄに母音で始まる語尾が続くと、ㅅが濃音[ㅆ]になり次の音節の初声に移る。回答は없어を[업ː써]と示す。これを없어요の注記に適用し、長音記号を省いた発音表記[업써요]を示した。
- 照合範囲はこの規則と없어요の注記に限る。ほかの見本や説明の言語的照合を意味しない。

## 動作・音声確認

- 注記のデータに対する自動テストと、端末による音声の実聴は別の確認である。実聴は未確認。
