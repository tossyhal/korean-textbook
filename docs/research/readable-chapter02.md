# 第2章の説明改訂

第1章の受け入れ方針に沿い、各節の見出しごとに意味、見る位置、選択手順、例の分解、迷いやすい点を補った。問題、解答、ID、タグ、語彙、出典の確認状態は変更していない。

- 第8節：안と못の意味の差、長い否定の語幹からの作り方、하다を含む語の位置と発音を説明。
- 第9節：語幹最後の母音による過去形の選択、縮約、하다と例外、否定と文の構成を説明。
- 第10節：最後の音節のパッチムとㄹによる予定形の選択、推量と否定、質問の読み方を説明。
- 第11節：数える対象による二つの数え方、単位前の形、時分・日付・人数・値段を途中の組み立てから説明。
- 第12節：知りたい情報と助詞を選ぶ手順、依頼の形の作り方、物と動作、促しと利益を伴う依頼の違いを説明。
- 第13節：希望と可能の形の作り方、最後の音節とㄹの判断、予定や否定との違いを説明。
- 第14節：復習の計画、読解・入力・聴解で注目する箇所と作文・発話の自己確認を案内。確認テストの文や解答は本文へ移していない。
