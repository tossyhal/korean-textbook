# 第3章の説明改訂

各見出しで意味と場面、形の作り方、文の分解、迷いやすい点を整理した。問題、解答、ID、タグ、語彙、出典と確認状態は変更していない。

- 第15節：고の並列と順序、語幹からの作り方、日課と場所、싶어요との違いを説明。읽고の発音補足は意味と作り方の後へ移動。
- 第16節：理由と関連する順序、母音による選択と縮約、過去と依頼の制約を説明。-(으)니까を語幹末のパッチムに応じて作る手順とㄹの扱いを追加。
- 第17節：지만による対比、語幹と時制、理由との違い、会話での使い方を説明。
- 第18節：範囲、追加と限定、所在・移動先・動作場所、予定と名詞を結ぶ形を説明。
- 第19節：文末の形容詞と名詞の前の形、パッチムとㄹ、좋다と좋아하다、感想の文を説明。
- 第20節：縮約と듣다、ㅂ・르・ㅡ、ㄹ・ㅅの頻出形を辞書形や続く形と対にして説明。
- 第21節：読解・入力・聴解で注目する位置と自己評価の進め方を案内。
