# 第8章の説明改訂

各節の目的と場面を踏まえ、文の分解と情報の探し方、作文・発話の手順、確認テストや復習から次の学習を選ぶ方法を補った。独立した技能別結果画面への案内は、実際に使える各節の確認テスト・復習・目次に合わせた。問題、解答、ID、タグ、語彙、音声、出典と確認状態は変更していない。

- 第50節：初見文の時・行為者・否定を結び、推測と分ける。
- 第51節：日記の出来事と感想、連絡の日時・場所を分解する。
- 第52節：言い換えで数量と否定を保つ。
- 第53節：問いと各ターンの条件に応じて答える。
- 第54節：復唱から入れ替え、自分の文へ進む。
- 第55節：迷った項目から本文や復習へ戻る。
- 第56節：確認テストと自己評価を振り返り、2〜4週間の復習を選ぶ。

## 参照範囲と限界

`AGENTS.md`、`docs/REFINEMENT.md`、第1・5章の改訂記録と第8章各節の既存本文・例文・問題を参照した。既存出典の再照合や新たな一次資料の照合は行っていない。本文全体の言語照合、母語話者確認、音声の実聴、実機確認は未実施。自動検査の成功はこれらの確認を意味しない。
