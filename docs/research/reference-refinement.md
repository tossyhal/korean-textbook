# 参照ページの照合記録

- [国立国語院「標準発音法」第2章](https://www.korean.go.kr/front/page/pageView.do?page_id=P000098)の単母音表では、ㅓは後舌・非円唇の中母音、ㅗは後舌・円唇の中母音、ㅜは後舌・円唇の高母音とされる。参照ページと字母ガイドでは、ㅓの唇と舌の説明を揃え、ㅗとㅜの舌の高さを対照した。説明は初心者向けの目安である。
- [Microsoft Learn「Korean IME」](https://learn.microsoft.com/en-us/globalization/input/korean-ime)は韓国語IMEのAアイコンを選んで가に切り替える手順と右Altキーを案内している。右Altキーの利用はキーボードや設定によって異なり得るため、参照ページにその条件を明記した。
- Appleの案内リンクの到達先は今回確認できていない。リンクの誤りとは断定せず、公式情報への案内を維持した。
- 上記は記載内容の個別照合であり、発音音声の実聴、IMEやiPhone・Windows実機での確認、全文の母語話者照合は未実施。
