# 外部レビューの教材・単語帳の追加対応

2026-11-12。第4節の実際に組み立てられる確認問題は책と이에요に変更し、練習の의사と예요の組を繰り返さない。第40節は並列文にある行動を問い、第48節は先生と駅で会う場面に変更した。組み立て後の設問ID・選択肢・解説を回帰テストで確認する。

第20節の사세요は居住を尋ねる疑問文にし、第24節の条件文は学校との距離と音楽を聞いた時の気分へ変更した。第23節は文脈のない몰라야 해요を外した。第27節の該当問題は既に家へ行く行動と、先生に自分の予定を話す場面に修正されている。第37節の교수님も既に質問の相手として扱われる。第39節の韓日混在表記を修正した。

単語帳に좀、또、나오다、代名詞언제を追加した。[国立国語院の언제](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=17860&nation=eng)は代名詞として언제부터などを挙げ、教材の언제 와요に対応する副詞とは別に収録する。頻度資料は品詞のみから語義を確定できないため追加4項目の順位は未設定。教材語彙531件と教材外322件の計853件。発音や使用場面を含む教材全体の言語照合を意味しない。

学習操作に必要な未実施の案内を残し、重複する未確認・採点仕様の説明を簡潔にした。未確認状態や音声の利用条件は変えていない。第33節の出典リンク名は뭐に訂正し、用例と留保は維持した。母語話者による全文照合、音声実聴、実機確認は未実施。
