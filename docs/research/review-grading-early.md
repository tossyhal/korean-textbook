# 前半教材と採点のレビュー対応

2026-11-12。未確認音声は実施数・得点に入れず、未実施として残す一方、完了に必須の問題から除外した。未確認音声以外の未実施問題と自己評価は従来どおり完了を妨げる。第43・44節の実データで確認した。

日本語の表記ゆれや解答の別形は対象問題に明示的に追加した。韓国語全体には互換正規化や空白削除を適用していない。第15・21節の고の聴解・読解は時間順を前提としない問いにした。第22節は쓰고が動作をつなぐ説明に直した。第4節の確認問題は別の語を用いた。

- 国立国語院の[-고](https://krdict.korean.go.kr/jpn/dicSearch/SearchView?ParaWordNo=78583)は並列・順序などの用法を記載する。前後の時系列を고だけから確定しない。
- 国立国語院学習辞典の[언제検索結果](https://krdict.korean.go.kr/eng/dicMarinerSearch/search?ParaWordNo=&mainSearchWord=%EC%96%B8%EC%A0%9C&nation=eng&nationCode=6)には代名詞と副詞が別見出しで載る。언제 와요の用例に合わせ副詞とし、언제부터等では代名詞の用法もある。
- 既存出典の[回答306190](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=306190)は今回取得できなかった。別の国立国語院の[回答327163](https://m.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=327163)は의사이에요と의사예요の双方を標準発音と説明する。未縮約形を許容し、通常の例文は縮約形にする。

これは個別事項の照合であり、教材全文の母語話者照合、未確認音声の実聴、実IME・実機検証は行っていない。音声や教材全体の確認状態は変更していない。
