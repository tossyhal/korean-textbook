# 採点と文法参照の統合確認

## 採点の契約

物理2ボル式の修飾キー名を問う第2節の問題に限り`latin`正規化を指定する。入力の前後の空白を除き、全角ASCII英数字を半角へ変換し、ASCII英大文字を小文字にする。内側の空白、句読点、ハングル互換字母は変換しない。字母入力やShiftの有無が意味を持つキー位置の問題には適用しない。その他の採点は従来どおりNFCと各問題の空白・句読点の設定を使う。

第7節の책이 없어요の訳には、既存の「ない」に加え「無い」「ないです」「無いです」の明示的な表記を追加した。固定された許容解との照合であり、任意の同義表現を意味解析するものではない。

## 文法参照の根拠

第20節のㄹ・ㅅの参照例は、教材の改訂で「여기에 사세요.」から疑問文「여기에 사세요?」へ変更された。同じ살다の例に結び直した。全165件の一意な文法項目について、初出節、指定段落または問題、指定された例文が実在し、表示内容が空でないことをテストする。例文や段落が欠落した場合は別の内容へ代用しない。

これはデータの結合と採点動作の検証であり、ネイティブによる言語照合や音声・実機の確認を意味しない。
