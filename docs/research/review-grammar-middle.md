# 第4〜6章の文法参照照合

初出日22〜42の文法IDを教材から重複排除して照合した。対象64件、明示した参照64件、解決できない参照0件。各項目の初出節の本文段落または同じ節の練習問題を参照し、場面別の項目は本文で実際に扱う範囲を設問に記した。

許可と禁止、動詞の現在・過去・予定の連体形、主体への尊敬と聞き手への丁寧さをそれぞれ区別した。進行と状態は初出節の進行と習慣の対比、希望を尋ねて提案する項目は初出節にある希望と計画の質問に範囲を限定した。禁止の既存の問題と例文は維持した。

動作検証として`pnpm exec vitest run src/content/grammar-reference.test.ts`と`pnpm run typecheck`が成功した。別途、教材から対象IDを動的に集計し、各参照が解決されることを確認した。この記録はネイティブ話者による言語照合、音声、実機の確認を意味しない。全章の網羅性はこの集計の対象外。
