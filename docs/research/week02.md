# 第2週の言語資料

確認日：2026-11-12。以下は資料で確認した個別事項であり、教材の自作文の自然さ全体や合成音声の確認ではない。

- [国立国語院・初級韓国語読解指導書](https://www.korean.go.kr/common/download.do?book_seq=294&c_file_name=48c417c6-047f-48f4-88a7-959f28e5e0ad_0.pdf&downGubun=bookDataView&file_path=bookData&o_file_name=%ED%95%9C%EA%B5%AD%EC%96%B4%EC%A7%84%ED%9D%A5-02-17.pdf)：時は固有数詞、分は漢数詞。30分は반ともいう。
- [国立国語院・数量を数える語](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=90&pageIndex=1&qna_seq=331063)：하나〜넷に対応する数冠形詞と11〜14の形。
- [国立国語院・月名と日付の分かち書き](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&qna_seq=329930)：月名の綴りと日付・時刻の原則および許容表記。유월と시월は続ける。
- [国立国語院・分かち書き](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&qna_seq=307291)：数と単位の原則、金額の慣例。
- [国立国語院学習辞典・補助動詞주다](https://krdict.korean.go.kr/m/jpn/searchResultView?ParaWordNo=77245&nation=jpn)：他人のための動作を表す用法。
- [国立国語院学習辞典・-ㄹ 수 있다](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=86664)：母音・ㄹ語幹の後の可能・能力。
- [国立国語院学習辞典・-을 수 있다](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=86661)：ㄹ以外の子音語幹の後の可能・能力。
- [国立国語院・오다の活用](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&qna_seq=318662)：2025-07-24回答本文と正書法35項解説を確認。보다は보았다／봤다を認めるが、오다は오았다を認めず왔다を用いる。
- [国立国語院・補助用言주다の分かち書き](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&qna_seq=305961)：回答本文で分かち書きが原則、例の続け書きも許容と確認。
