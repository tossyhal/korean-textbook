# 実践課題の設計確認

世宗学堂財団の[入門教材紹介](https://nuri.iksi.or.kr/front/cms/contents/layout2/learningsejong/detail.do?csCmsMastrSeq=5318&menuSn=651)は、字母の発音、子音・母音の読み書き、挨拶を入門の内容として挙げる。[初級ワークブックの目次](https://nuri.iksi.or.kr/front/cms/contents/layout2/learningsejong/detail.do?csCmsMastrSeq=15227&menuSn=649)は、ハングル入門に続き挨拶、物の場所、学習や買い物などの場面を並べている。これらを参考に、本教材では字母の入力と音の観察から短い文、場面での伝達へ進める。出典は設計の参考であり、本教材の個々の韓国語や音声が照合済みであることを意味しない。

56節の実践課題を到達目標・指示・例・自己確認項目の対応で確認した。第1〜3節は文字入力と発音、第12・29〜31節は場面の発話、第43・44節は発音の観察とした。第4〜11節などは既習の形を使った短文、第13〜28節は文の組立、第32〜42節は場面や自分の情報を用いた文、第45〜56節は情報の伝達・日記・メッセージなどとして残した。自由に作る文章は自動採点しない。

第11節の任意の日付に対する10月専用の条件、第12節の存在しない返答、第19節の不要な両表現の要求、第45節の作文と発話の例、第50節の発話の予定数を修正した。聴取ができないときの未実施も明記した。

確認は課題設計の点検であり、全文の母語話者による言語照合、実際の端末音声の聴取、録音品質や実機の確認は未実施である。

発話の自己評価には、自由な内容の伝達に加えて第43・44節の口や舌、息など発音の観察も含まれる。発音の熟達を自動判定した数ではない。録音比較は利用可能な場合の補助であり、実施できない聴解や書取は未実施として扱う。
