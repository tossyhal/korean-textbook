## 修正を要する指摘

### P2：同綴り・同品詞の一意一致だけでは別語の頻度順位を付与する

`src/content/wordbook/lesson-ranks.json:306`の`vocab-jigak: 5284`と同ファイル423行の`vocab-beda: 3750`は、教材が示す語義と原資料の項目が一致しない。

| 教材ID      | 教材の意味           | 付与した順位の原資料の内容  | 問題                                                   |
| ----------- | -------------------- | --------------------------- | ------------------------------------------------------ |
| vocab-jigak | 지각：遅刻           | 5284 / 지각04 / 명 / 知覺   | 遲刻の順位として知覺の順位を表示する                   |
| vocab-beda  | 베다：枕などを当てる | 3750 / 베다02 / 동 / 목을 ~ | 枕を当てる語の順位として「首を切る」語の順位を表示する |

ローカルの一次資料`.local-handoff/nikl.txt`をCP949で読み、上記の行を確認した。公式の[韓国語基礎辞書「지각（知覺）」](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=27752&nation=eng)と[「베다（切る）」](https://krdict.korean.go.kr/ind/dicSearch/SearchView?ParaWordNo=14464&nation=ind&nationCode=4)、[国立国語院による「베개を頭の下に当てる베다」の説明](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&qna_seq=305546)も照合した。

原資料に同形同品詞が一つしかない場合でも、原資料にない別語へ一致することがある。「完全な語義照合ではない」と注記しても、すでに判明した誤対応を表示する理由にはならない。少なくともこの2件の順位を削除し、順位未照合とする。順位付与時には原資料の풀이と教材の意味を確認し、誤対応を回帰テストに含める。既存のテストは昇順と가다の順位を確認するだけなので、この2件も通過する。
