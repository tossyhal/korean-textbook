## 指摘

### P2：入力診断の全問が正答の文字列を提示しており、第1〜3課を省略する根拠として弱い

- 対象：`src/features/assessment/bank.ts:34`〜38、`src/App.tsx:867`〜872。
- 入力5問はすべて「『이』をハングルで入力」の形式で、提示文字のコピーだけでも5/5になる。文字区分も最初の2問は問題文にある字形と選択肢の照合で正答できる。この結果をそのまま文字・入力の習得と結び付け、第1〜3課の省略先を案内している。
- 最小修正案：入力区分を「字母の組み合わせから音節を作る」など正答の完成形を見せない問題へ変更する。提示字形の転記を残す場合は、その範囲を説明し、読字や音節構成まで確認できたという扱いにしない。ペースト自体の禁止は必要ない。

### P2：診断を一律「初見問題」と表示するが、既存教材と同じ評価内容が含まれる

- 対象：`src/features/assessment/bank.ts:47`〜56、`src/App.tsx:877`。
- `diagnostic-12`は`src/content/lessons/week01/day04.ts:227`の出口問題と同じ`의사가 아니에요`の意味を同じ正答で問う。`diagnostic-13`も第5課の例文・練習に出る`가방이 없어요`をそのまま用いる。先取り診断は学習後でも開けるため、IDの独立だけでは学習者にとっての初見性を保証できない。特に第4課の出口問題は、診断でその答えを見た後にも別IDの初回として採点される。
- 最小修正案：診断の評価文を既存練習・出口テストの評価文から分け、語彙や場面の組み合わせを変更する。一律の「初見問題」は「診断用の問題」などへ変更する。既存の文型や単語を使うこと自体を問題とはしない。

### P2：文字・入力の診断誤答から教材へ戻るリンクがない

- 対象：`src/features/assessment/bank.ts:85`〜95、`src/App.tsx:984`〜989と1025付近。
- 最初の10問はタグが空。誤答すると問題IDの復習だけが登録されるが、復習画面の`source`探索は課に属する問題・語彙・文法だけを対象とするため、診断問題の教材リンクが出ない。文字・入力が弱い初心者ほど説明のある課へ戻れず、先取り先の提案もリンクではなく文字列にとどまる。仕様の「弱点へのリンク」に不足する。
- 最小修正案：診断問題に安定した関連課・節の参照を持たせ、問題解説と復習画面から第1〜3課の該当節へ案内する。基本文区分も、語彙だけではなく問う文型に対応する参照を用意する。

## 確認済み・留保

- 復習の閲覧状態は全履歴を順に走査し、`viewed`で追加、自己評価で削除する。したがって「閲覧→理解した→次回」の時点では再び`recalled`が可能。現実装に永久無効化の不具合はない。評価せず閲覧だけした項目は翌日も閲覧済みのままであり、未完了の同じ回を継続する挙動として整合する。日付だけで解除すると、翌日開いただけで未完了の閲覧を自力想起と記録できてしまう。
- 日次上限はローカル日付の自己評価済み問題IDの集合で20件を数え、リロード後も維持する。閲覧だけでは完了扱いにしない。上限に達すると未完了は翌日以降へ残す。
- 出口テストの技能別結果は固定採点と自己評価、初回・未実施を分離する。診断は聴解を未実施と明記し、第三者言語照合や音声確認を済んだとは表示しない。
- バックアップは診断IDを参照集合に含め、追加された`reviewHistory.id`も検証する。旧データの空履歴補完を実装している。
- 第55・56課の条件付きリンクは実装されているが、両課は未収録。実教材での接続検証が未実施という記録は適切。
- `mise run test -- src/features/assessment/bank.test.ts`は2件成功。追加の読み取り用実行で、不明な履歴IDの復元拒否、自己評価後の閲覧状態解除、翌日への再設定を確認した。今回、ブラウザー・実機・言語内容の外部照合は実施していない。
