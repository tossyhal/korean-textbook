# バックアップの学習位置修正

第1〜3課の「文字を組み立てる」は画面から学習位置として保存されるが、バックアップ取込時の教材位置一覧に含まれていなかった。各課の実在する位置として追加し、第4課や任意の位置は引き続き拒否する。ホームの診断と学習結果へのリンクは別段落にした。

## 動作検証

- `mise run test`: 30ファイル、138テスト成功。第1〜3課それぞれのバックアップ往復、任意の位置と第4課の組み立て位置の拒否を追加。
- `mise run lint`: 成功。
- `mise run build`: 型検査とビルド成功。
- `mise run format:check`: 担当外の第8週教材と既存レビュー文書の計9ファイルで整形違反があり失敗。担当変更ファイルは個別に整形検査する。
- ブラウザでの見た目と実機確認は未実施。言語内容・音声の照合はこの変更の対象外。
