# 初学者向け教材の修正記録（第1〜28課）

2026-11-12。SOL-02/03/05/06とOpusレビューの前半指摘を対象に、教材編集として対応した。母語話者照合、端末音声の実聴、実機確認は行っていない。

- 第5・8・15課：없어요[업써요]、읽어요[일거요]、읽고[일꼬]を使用前に分け、原綴りと発音を区別。指定された国立国語院の発音解説を実読し、適用条件を記録した。第15課に자다と現在・過去を導入し語彙登録。
- 第5・15・16・18課：物と場所の指示語、所有의・제、形容詞の述語、名詞の列挙・同行者の助詞を段階的に導入。第16課の形容詞は接続より前に扱い、既存語彙の初出IDを維持。
- 第1・4・10〜12課：初声と入力配列を補い、日本語への助詞混入・誤訳を修正。아니요・감사합니다を丸ごとの表現として導入し語彙登録。数と助数詞、열두時、依頼と語順の指示を補正。第11課の日付の分かち書きは国立国語院の回答で確認し既存説明を維持。
- 第15・17・18・20課：移動後の動作を고で模範とした箇所を並列の動詞へ置換。対比の助詞、移動起点에서と時間の부터を整理し、場所の부터を非文とは断定しない。聞く／尋ねるの曖昧な出題は「説明を聴く」に限定。
- 第23・27課：必要表現の돼요形、尊敬と促しの同形、합니다体の名詞形・疑問形・鼻音化、名前の尋ね方を補足。
- 第7・14・21・28課：練習欄の操作方針問題を韓国語の意味理解に変更。第28課の読解と聴解でほぼ同一だった素材を別の場面に変更。

Opusレビューの「ㅎ関連の説明が全体にない」という断定は、既存第44課を確認した結果そのまま採用しない。第44課と第43課の復習・平音の例は後半担当の範囲。音声再生や細かな音の聞き分けの正確性は未確認である。日付、出発点、発音の照合先は[調査記録](../research/beginner-foundations.md)に記載した。
