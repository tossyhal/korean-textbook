# 韓国語教材監査レポート（全56課・教材データ）

## 結論

**本当にゼロから始める人向けの教科書としては、現状では不十分です。** 課ごとの構成（本文・例文・演習・出口テスト・作文）は全56課に揃っています。ただし、改善すべき点が五つあります。

1. **発音変化の説明に大きな抜け**があります。Day3で「後で扱う」とした複数子音のパッチムは最後まで出てきません。ㅎの弱化・激音化、口蓋音化、`-ㅂ니다`の鼻音化も説明がありません。そのため、既習の頻出語（좋아요、같이、괜찮아요、감사합니다、읽어요、없어요）の発音を学ぶ機会がありません。
2. **不自然な韓国語や誤解を招く対応を、模範や正解として教えている**箇所があります。移動動詞を-고でつなぐ例、「聞きます」を듣다にする例、「より＝더」などです。
3. **基本的な機能語がほとんど説明されていません。** 이/그/저＋名詞（この・その・あの）、와/과・하고、제/제가などです。
4. **第7・8週の出口テストに、韓国語ではなくアプリの方針を問う問題が混ざっています。** 自動採点の得点が理解度を表しません。
5. 第5週以降、**本文の後半が語彙の羅列になっている課**があります。テストの多くも、2〜3択でキーワードを照合するだけです。

既知のUI課題（章表示、先取り診断、想起→復習、目次→タブ）は指摘の対象から外しました。

## P1（教える内容の誤り・学習の妨げになる欠落）

### P1-1 発音変化の大きな抜け（第1週〜第7週）

- **該当箇所：**
  - `week01/day03.ts:113`に「複数子音のパッチムは後で扱います」とありますが、教材全体をgrepしても겹받침、激音化、口蓋音化、流音化、ㅎ脱落の説明は0件です。
  - Day44（`week07/day44.ts`）は「既習語で起きる発音変化の復習」の課ですが、扱っているのは代表音、連音（옷이・꽃을）、鼻音化、濃音化（먹다・국밥）だけです。
- **初心者への影響：** 既習の頻出形の音と綴りを結び付けられません。そのため聴解でも聞き取れません。
  - 좋아요[조아요]、많아서[마나서]、괜찮아요[괜차나요]
  - 좋다・좋고[조타・조코]、못 해요[모태요]
  - 같이[가치]（Day34で導入）、연락[열락]（Day24）
  - 갑니다・먹습니다・감사합니다・반갑습니다[-ㅁ니다]（Day4・27）
  - 읽어요[일거요]、읽고[일꼬]、없어요[업써요]
  - 갈 거예요[갈꺼]、할 수[할쑤]
- **修正案：**
  - Day44に「ㅎの脱落と激音化」「口蓋音化」「複数子音パッチム（ㄺ・ㅄ・ㄶ・ㄵ）」「-ㄹ後の濃音化」の節を足し、すべて既習語で例示します。
  - Day27の합니다体と、Day8の못＋하다/母音動詞にも、その場で発音注記を入れます。

### P1-2 平音の有声化と、実際の聞き分け練習がない（Day1〜3・Day43）

- **該当箇所：**
  - Day43 section-2に「位置で有声音に近く聞こえる」という一文があるだけで、例がありません。
  - Day43の練習12問はすべて概念を問う選択問題（唇の形・分類名）です。実際に聞き分ける問題は、確認済み音声が条件の`critical`1問だけで、実質未実施になります。
- **初心者への影響：** 日本語話者が最も迷う「바다の2つのㅂ・ㄷの違い」「고기のㄱ」を知らないまま、第7週の「音を鍛える」週を終えてしまいます。
- **修正案：**
  - 語頭と母音の間の対比（바다、고기、가게、부부）を本文に入れます。
  - 自己判定式の最小対リスト（불/풀/뿔、달/탈/딸、살/쌀、자다/차다/짜다）を、採点しない「聞く→言い分ける→録音」課題として追加します。

### P1-3 移動・姿勢の動詞に-고を使った不自然な模範（Day15）

- **該当箇所：** `week03/day15.ts`
  - 会話「아침에 일어나고 세수해요」「집에 오고 손을 씻어요」
  - production model「집에 오고 쉬어요」
- **問題：** 移動して、その先で次の行動をする場合は、가서/와서/일어나서が自然です。本文はこの制約に触れず、不自然な形を模範にしています。Day16で가서を教えますが、Day15の模範を訂正していません。
- **修正案：** 該当文を일어나서/와서に直します。Day15本文に「가다・오다・일어나다など、前の動作の結果を伴う順序は次課の-아서/어서」という注意を加えます。

### P1-4 「知らないので聞きます」を몰라서 들어요にしている（Day20 `day-20-exit-03`）

- **問題：** 日本語の「聞く（尋ねる）」に、듣다（聴く）を当てています。尋ねるなら물어봐요が自然です。
- **影響：** 日本語話者に典型的な誤りを、出口テストの正解として固定してしまいます。
- **修正案：** 設問を「知らないので（説明を）聞きます」→몰라서 설명을 들어요などに変えます。または「聴く」に限定します。Day20本文に「聞く＝듣다/묻다」の注意を入れます。

### P1-5 「より」を더とする説明と採点（Day36 section-3、Day39 section-1、`day-39-ex-8`）

- **問題：**
  - 本文が「더は『より』」と説明しています。
  - 練習「「より」の韓国語」の正解が더だけです。
  - 「AよりB」の「より」は보다に当たるので、보다と答えた学習者が不正解になります。
- **修正案：** 「보다＝〜より、더＝もっと（より多く）」と分けて説明し、設問を「『もっと』の韓国語」に直します。

### P1-6 場所の始点を부터で教え、에서〜까지を扱っていない（Day18 section-0・例文）

- **問題：** 「서울부터 부산까지」を範囲の基本例にしています。場所の起点は서울에서 부산까지が標準的で、本文は에서（起点）に一言も触れていません。
  - 疑義：부터も文法的には成り立ちますが、初級の基本例としては不適切だと判断しています。
- **修正案：** 「時間は부터〜까지、場所は主に에서〜까지」と対比させ、例文を差し替えます。

### P1-7 中核の機能語を導入しないまま使い続けている

| 語・形                             | 初出の使用                                                | 説明の状況                                                      |
| ---------------------------------- | --------------------------------------------------------- | --------------------------------------------------------------- |
| 이/그/저＋名詞（この・その・あの） | Day16「이 옷은」、Day19「이 책이」以降多数                | 説明なし（grepで0件）                                           |
| 하고（〜と）                       | Day29 `day-29-exit-01`「국수 두 그릇하고」、Day35、39、42 | 説明なし                                                        |
| 와/과                              | Day34から使用                                             | Day37でようやく「와は〜と」の一言のみ。과との使い分けは説明なし |
| 제/제가                            | Day36「제 취미」、Day50「제가」                           | 제はDay38で説明。제가は説明なし                                 |
| 아니요、감사합니다                 | Day8、Day29以降                                           | 語彙登録・説明なし                                              |
| -(으)ㄹ게요                        | Day30 `day-30-ex-12`（入力採点あり）                      | 未習                                                            |
| 보다（比較）                       | Day35 `day-35-exit-14`「이것보다 저것이」                 | Day36・39より前に出題                                           |
| 옆                                 | Day31 `day-31-exit-04`                                    | Day32で導入                                                     |

- **修正案：**
  - Day5（指示語）に이/그/저＋名詞と이거/그거/저거を足します。
  - Day6か12に하고/와·과（パッチムでの使い分け）を足します。
  - Day4に아니요・감사합니다、Day36に제/제가を入れます。
  - Day30・31・35の該当問題は、既習の語に差し替えます。

### P1-8 出口テストで「アプリの方針」を採点している（第7・8週、各週末テスト）

- **該当箇所：**
  - 各週末テスト（`day-07/14/21/28/35/42/49-ex-01`）：唯一の練習問題が「音声を再生できない聴解は→未実施」
  - `day-46-exit-4/5`、`day-47-exit-3/4/5`（voiceURIの条件など）、`day-48-exit-4/5`、`day-49-exit-07/08`、`day-52-exit-4/5`
  - Day46〜48の練習の約半数
- **影響：** 韓国語を理解していなくても得点でき、技能別の得点と「8割の目安」が意味を失います。
- **修正案：** 方針の説明は本文（または採点しない確認）に移し、出口テストは韓国語の初見問題だけにします。週末テストの練習欄には、その週の文法を使った実際の練習を置きます。

### P1-9 聴解の音声テキストに「가:」「나:」が含まれる（Day48〜52・56）

- **該当箇所：** 例として`day-48-ex-listen-1`、`day-49-exit-listen-1〜4`、`day-56-exit-listen-1〜8`。audio.textが「가: 언제 만나요? 나: …」になっています。
- **問題（疑義・実機未確認）：** `src/features/audio`をgrepした限り、話者ラベルを除く処理は見当たりません。合成音声がこのまま「가」「나」と読み上げる可能性があります。나は「私」とも聞こえ、初見の聴解を妨げます。また、話者が1つの声のため、二人の会話として区別できません。
- **修正案：** 発話を配列に分けて話者ラベルを表示専用にするか、ラベルを除いて再生します。

## P2（不自然な表現・説明不足・評価設計の弱さ）

**第1・2週**

- **Day1：**
  - 入力問題（ㄴ・ㅁ・ㄷ・ㅂ）を出していますが、本文で示す配列はg/k/sだけです。全配列はDay2の本文と参照ページにあり、Day1から明示的なリンクがありません。
  - 「初声」が定義されていません。
  - production promptの「가와 나を」は、韓国語の助詞와が混入した誤記です。
- **Day4：**
  - 「의사이에요は正しいか→正しい」（`day-04-ex-03`）や、Day7の「저는 의사이에요」（`day-07-exit-08`）は、規範上は許容でも会話ではまず使いません。「許容されるが通常は예요」と明記すべきです。
  - 「의사가 선생님이에요（医師が先生です）」（`day-04-exit-01`の根拠）は場面が不自然です。
  - 이/가 아니에요の이/가を「主語の助詞」と説明していますが、補語であることへの注意がありません。
  - 自己紹介に名前・国籍（일본 사람이에요、이름）や、イントネーションによる疑問文の説明がありません。
- **Day8：** 못 읽어요[몬닐거요]、못 해요[모태요]など、못が絡む発音変化に注記がありません。
- **Day10：**
  - 会話「친구를 만날 거예요?」の訳「友達**にも**」は誤訳です。
  - 本文に「다음은次、계획은計画、공원은公園、도서관은図書館」と、韓国語の은が「は」の代わりに混入しています。
- **Day11：**
  - 「물이 스무 개」は不自然です（병を使うべき）。
  - 며칠（何日）と、십육[심뉵]などの数字の発音がありません。
  - 「오 월 삼 일」の原則表記は疑義です（오월は1語の名詞として辞書に載っているはずです）。
- **Day12：**
  - 「物を飲むよう依頼する→물을 마셔 주세요」（`day-12-exit-08`）は、「自分のために飲んで」という意味になり不自然です。마시세요にすべきです。
  - 「무엇을 집에서 마셔요」（`day-12-exit-06`）は、不自然な語順を強制しています。
  - -아/어 주세요と-(으)세요の両方に同じ訳（「本を読んでください」）を当て、違いを説明していません。

**第3・4週**

- **Day15〜16：** 자다（寝る）が未導入のまま、잤어요・자요・잠을 못 자요で使われています。
- **Day17：** 「책을 읽지만 영화를 안 봐요」は、対比なら은/는が自然です（訳も「は」になっています）。
- **Day20・27：** 「여기에 사세요」の訳が、Day20では「住んでください」、Day27では「住んでいらっしゃいます」です。同じ形が依頼にも主体尊敬にもなることを、Day27で明示的に説明すべきです。
- **Day21：** 열두 시が出ますが、열둘→열두は未習です。
- **Day23：** 会話で非常に多い-아/어야 돼요に触れていません。
- **Day27：**
  - 「성함이 뭐예요?」は不自然です。성함이 어떻게 되세요?が定型です。
  - 합니다体に입니다/-습니까がなく、`-습니다`の発音[씀니다]の説明もありません。
- **Day28：**
  - 「안 재미있었어요」（`day-28-exit-08`）は재미없었어요が自然です。
  - 聴解3〜5は、読解5〜7とほぼ同じ文で、読解の記憶で答えられてしまいます。

**第5週**

- **Day29：**
  - 「一人前を한 명としない」と書きながら、인분（1인분）を教えていません。
  - 「영수증은 있어요?」は不自然です。
- **Day30：**
  - 로/으로のㄹ例外（지하철로）を説明していません。
  - 「현금에는으로」に助詞の混入があります。
- **Day31〜34：**
  - 「시간은時刻」「휴지는」「보고서는」「재미있아서는」「어디에ある」など、助詞の混入や誤記が多数あります。
  - Day33は仕様の「チェックイン」を扱っていません（체크인、예약했어요、이름으로 예약）。
- **語彙の羅列：** Day33〜34の本文後半に、例も練習もない語を10〜16語並べています（참석 여부、도착 예정、기회、소음など）。同じ状態はDay39〜41（감동적이다、평가、전후、귀가、기록、가능など）にもあります。A1水準を超えた語を水増ししているので、削るか、例文と練習を付けてください。
- **Day35：**
  - 「밥 두 개」（`day-35-exit-01`）は不自然です（공기밥 두 개、밥 두 공기）。
  - 「베개가 하나뿐이에요」（`day-35-exit-11`）の뿐は未習です。
  - 聴解の1問目（`day-35-exit-listen-1`）が、読解13問目（`day-35-exit-13`）とまったく同じ文です。

**第6週**

- **Day32：** 「다시 말씀해 드릴까요?」は疑義です（다시 말씀드릴까요?が一般的と考えます）。
- **Day37：**
  - 「교수에게 질문해요」「교수는 질문해요」（`day-37-exit-02`）は、自分の教授に님を付けておらず失礼です。Day27で教えた교수님께と矛盾します。
  - 想定学習者（エンジニア・大学院生）が自分の研究や開発を説明する文型（연구하고 있어요、개발해요）がありません。
- **Day40：** 「휴식을 했어요」は不自然です（쉬었어요、휴식을 취했어요）。
- **Day42：** 노래를 부르다、배워요が未習です。

**第7・8週**

- **Day45：** 聴解の数字が1〜4と이십 분だけで、Day11の漢数詞・値段・日付を使っていません。「素早く」理解する訓練になっていません。
- **Day49：** 「비가 와서 차를 사요」は意味が不自然で、차（お茶・車）の曖昧さもあります。

**全体**

- **想起問題・到達目標の量産：** Day32〜34の想起は共通です（주세요/어디에 있어요?）。Day43〜45の想起は「学校」「水」の単語だけです。Day32〜34・39〜41の到達目標は「〇〇を理解する」という定型文です。課ごとに固有の内容に直してください（UIの「復習」化とは別の、教材内容の問題です）。
- **週末テストの設計：** 読解の大半が2〜3択でキーワードを照合するだけです。理由・条件を複数統合する問題や、似た文を区別する問題を増やすべきです。

**発音・入力参照（`src/features/reference/index.tsx`）**
