# 学習結果の集計範囲と言語属性

- 全履歴に加え、収録済みの各週の確認テストを選択できる。初期値は実施済みのうち学習順で最後のテスト、実施がなければ全履歴。未実施テストも明示して選べる。
- 選択範囲の出口テストと作文・発話の自己確認を集計し、推薦先は全収録課のメタデータから解決する。初回回答と自己評価を混ぜず、未実施を0点にしない。
- 日本語と韓国語が混在する教材テキストに共通の言語属性付与を適用した。入力欄やローマ字キー列は変えていない。
- 検証：型検査、lint、担当ファイルのformat、対象Vitest（7件）、buildが成功。Playwrightで音声APIなしの状態、390px幅、第7課の回答からの初期選択、全履歴と未実施の第14課への切替を確認した。agent-browserでも同じ切替と幅を確認した。
- 音声の発音と言語的照合、実機での確認は行っていない。
