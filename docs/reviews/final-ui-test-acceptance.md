## 録音比較の手本表示

対象は`src/features/recording/index.tsx`、`tests/browser/media.spec.ts`、`tests/browser/roleplay.spec.ts`、`docs/reviews/recorder-source-label.md`。

- 音声パスがない場合は端末の韓国語合成音声と明記し、音声内容と発音の品質を未確認としている。第1課、発音ガイド、ロールプレイの追加検査で表示を確認した。
- `src/content`内に音声の`path`指定は見つからず、現在の教材に対する表示は実装と整合する。
- 将来パスが指定された場合も、ファイルと失敗時の合成音声の両方を案内し、品質を未確認とする。ファイルの確認状態に依存して合成音声を確認済みと表示する構造ではない。`AudioEngine.play`のファイル失敗時の合成音声への切り替えとも整合する。
- 追加した表示検査に`first()`等による複数一致の回避はない。既存の録音形式、トラック停止、拒否・非対応、ロールプレイの状態復元の検査も維持されている。
- 実装記録はモックによる動作確認と実音声・実機の未確認を分けており、確認範囲の過大な申告はない。

## 出典リンクの完全一致

対象は`tests/browser/curriculum.spec.ts`、`docs/reviews/curriculum-source-selector.md`。

- 変更は出典名の検索への`exact: true`追加のみ。同名文字列を含む別の資料名への部分一致を防ぐ。
- `#sources`内のリンクという範囲指定と、各出典の`source.url`に対する`href`検査を維持している。
- `first()`、`nth()`、例外抑制、条件付きスキップ等は追加されていない。同じ完全一致名のリンクが複数ある場合もstrict modeで失敗するため、曖昧さを隠す検査弱化はない。
