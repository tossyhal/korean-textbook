# 学習動線・単語帳UIの独立レビュー

2026-11-12。基点`ce0df21`の作業ツリーを確認。対象は`src/App.tsx`、`src/features/learning/style.css`、`src/features/audio/index.tsx`と関連ブラウザテスト。教材の言語、頻度順位・語義、productionスキーマと成績集計の正しさは対象外。他の独立レビュー結果は参照していない。ソースの変更とコミットは行っていない。

## 結論

P1なし、P2が1件、P3が2件。本文→練習→実践→確認テストの動線と保存・復帰は機能する。単語帳のページ切替後の閲覧開始位置を修正してから完了とする。

### P2：単語帳のページ切替後に新ページの末尾から表示される

- 場所：`src/App.tsx:1514-1529`、単語帳ページ送り。
- 再現：`#/reference`で40語を表示し、末尾の「次へ」を押す。
- 実測：切替後も`scrollY=3407`で、次ページ先頭の`.wordbook-entry`の上端が`-2895.421875px`。表示内容は41〜80語へ更新されるが、新ページ先頭は画面外のまま。
- 影響：頻度順に読み進める際、毎ページ上方向へ戻る必要がある。そのまま次へ進むと新しい語の大半を見落とす。キーボードでもページ送りへフォーカスが残り、新ページ本文を通過してしまう。
- 修正：ページ切替後に新しい語群の先頭か件数見出しへスクロール・フォーカスを移し、更新した範囲を認識できるようにする。「前へ」も同じ動作にする。現在のページ移動テストは件数だけを確認しており、この回帰を検出しない。

### P3：PCの縦タブが上下キーと縦方向のARIAを持たない

- 場所：`src/App.tsx:719-739`、`src/features/learning/style.css`の`.lesson-tabs`。
- PCでは縦配置だが、`aria-orientation`がなく、矢印操作は左右だけ。Home/Endと左右による操作自体は成功する。
- 推奨：PCの縦配置では上下キーにも対応する。狭幅の横配置を含め、見た目と支援技術へ伝える方向を揃える。

### P3：短い韓国語の再生ボタンが44px幅に満たない

- 場所：`src/features/learning/style.css`の`.word-audio`。
- 390px幅で「수」のボタンは約21.1×44px、「있다」は約35.8×44px。復習ボタンは44×44pxで、横方向の重なりはない。
- 推奨：単語の再生対象にも`min-width:44px`程度を確保する。現状でも周囲の空間があり、操作不能やWCAG違反と断定するものではない。

## 確認した動作

- 本文には「練習へ進む」があり、次節リンクは確認テスト内に限定。確認テストへ移るだけで未実施の節が完了することはない。各工程から前後へ移動できる。
- タブの選択状態、panelの対応、Home/End・左右キー、弱点リンクの位置指定、スクロール位置・下書きの再訪復帰を確認した。typing/speakingのラベル分岐と旧自己評価offset維持をコードで確認した。
- 設定と出典・メモの操作は通常メニューから撤去済み。旧`?sources`は本文へ安全に復帰し、既存のnotesを消さない。旧settingsはHomeへのフォールバックになる。
- データ管理はHomeから到達できる。JSON書き出し、適用、取消、破損拒否の既存テストが成功した。追加のブラウザ確認で、新語SRS25件・旧notes・旧sources位置を`exportBackup→parseBackup`へ通し、全て保持された。
- 教材外のwordbook由来IDを25件登録した場合、復習画面に語が表示され、日次表示は20件へ制限された。手動追加・解除、再読込保存、回答履歴保持のテストが成功した。
- 全件からの検索、40件ページ移動、品詞、意味非表示、文法切替・本文説明検索を確認。意味非表示の条件は例文の日本語訳にも適用される。検索・品詞変更はページを0へ戻す。
- 韓国語音声0件の環境で単語を押すと失敗メッセージが表示された。Referenceは検索・品詞・ページ・表示切替・離脱時に音声停止とrequest世代更新を行い、旧Promiseによるエラー更新を抑止する。
- 390pxの本文と単語帳をagent-browserで操作・撮影。横方向のはみ出しなし。工程ボタン44px高、復習アイコン44×44px。復習アイコンのラベルと押下状態がある。音声オプションがdetailsへまとまり、通常画面の操作密度は下がっている。
- 頻度資料の出典リンクと2003年／2002年、順位未照合の扱い、TTS未確認の表示がある。頻度順位の実証や商用資料との内容比較はこのレビューでは行っていない。
