# 第1章〜第8章 guided-review-baseline レビュー（読み取りのみ）

## 結論

要求の骨格は入っています。具体的には、左側のタブで本文→練習→実践→確認テストを切り替えられ、本文を下まで読んでも次節へ飛ばなくなりました。設定ページと各節の出典・メモも撤去され、第1章第1〜3節は入力課題に直っています。単語帳は834項目で、音声・品詞絞り込み・頻度順表示があります。

ただし、P1が5件あるため、このままでは受け入れられません。主な理由は次の3つです。

- 完了できない節、または完了するには自己評価で虚偽を申告するしかない節がある。
- 自然な順路で進むと「完了」の操作を飛ばしてしまう。
- 「頻出順」の単語帳から最頻出語が抜けているか、末尾に回っている。

| 観点                        | 判定                                                                                                                               |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| ①順路・タブ・次節           | 部分的に未充足。タブと自動遷移の廃止はできている。ただし、末尾の主ボタンを押すと完了を飛ばし、完了できない節が3つある              |
| ②設定/出典メモ撤去・互換    | おおむね充足。互換は保たれている。ただし声の選択と、声がない端末向けの案内まで消えた（P2）                                         |

## P1

### P1-1 第7章第1・2節（day43/44）は誰も完了できない

- **根拠**：
  - `week07/early-shared.ts:24` で確認テストに `requiresVerifiedAudio = true` が付いており、その音声は `unverified` のままです（`early.test.ts:21-30` で固定されています）。
  - `progress.ts:135-137` では、利用できない問題を `done=false` として数えます。
  - `progress.ts:164` の `complete = rows.every(done)` が真にならないため、`App.tsx:1029-1033` の「この節を完了する」は常に無効です。
- **影響**：
  - 画面には「確認テストをすべて実施し…」と表示されますが、学習者には実行する手段がありません。
  - 仕様197行目（再生できない聴解は「未実施」にし、他の学習は続けられるようにする）と矛盾します。
- **修正案**：完了判定から「利用できない問題」を除外し、未実施の件数は別に表示します。

### P1-2 第7章第5節（day47）は、韓国語の声が2つない端末では完了できない

- **根拠**：
  - `listening-transfer/index.tsx:84-87` は「この練習は未実施・得点なしです。他の学習は続けられます。」と表示します。
  - しかし `App.tsx:1032` と `1041-1043` は、`voiceTransferRuns` がないと完了できない条件になっています。
  - さらに実践のチェック項目「作文：別文の時を記したか」「原文と情報を照合したか」も、この練習を実施した前提で書かれています。
- **修正案**：声が足りないときは、この練習を「未実施」として完了条件から外します。チェック項目にも「実施できた場合のみ」の扱いを入れます。

### P1-3 必須チェックに「実施できた場合」の項目が混ざり、完了するには虚偽の自己評価が必要になる

- **根拠**：`progress.ts:215` の `productionComplete` は、チェック項目を**すべて**チェックしないと完了できません。
- **該当する節**（`resolved.json` の1〜1132行で確認）：
  - **文言に条件が付いているのに必須**：第7章第1・2節（「音声を聞けた場合、録音と比較して…」）、第8章第7節（「録音できた場合、語尾まで聞き直したか」）
  - **録音を無条件に求める**：第4章第7節、第5章第4〜7節、第7章第3〜7節、第8章第1〜6節（計16節）。マイクが使えない学習者は正直にはチェックできません。
  - **音声の再生に依存する**：第7章第4節（メモから）、第7章第5節（P1-2）、第7章第6節（聞いた内容と照合）、第8章第3節（書取を原文と照合）
- **影響**：自己評価の記録が、技能を実施した実績として見かけ上積み上がります（技能実績の偽装）。
- **修正案**：チェック項目に「できた／できなかった（未実施）」の区別を持たせ、完了条件は実施できた項目だけで判定します。未実施は結果ページに別に表示します。

### P1-4 末尾の主ボタン「次の節へ」は完了処理を飛ばす

- **根拠**：
  - `App.tsx:1046-1056` の主ボタン「次の節へ」は、未完了でも常に表示されます。
  - 「この節を完了する」（`1027-1037`）は主ボタン扱いではなく、確認テスト欄の途中にあります。
  - 自然に末尾へ進むと `complete()` が呼ばれないため、`reviewTargets` が復習に登録されず、目次は「学習中」のまま残ります。
- **影響**：要求「各末尾を自然に進むと全工程を行える」のうち、完了と復習登録の部分が満たされていません。
- **修正案**：主ボタンを「完了して次へ」にまとめます。完了できないときは足りない項目を示し、「未完了のまま次へ」を副ボタンにします。

### P1-5 「頻出順」の単語帳から最頻出語が抜けているか、末尾に回っている

- **欠落**：
  - 次の語は、834項目の `korean`・`dictionaryForm` のどちらにも完全一致で見つかりませんでした：것、하다、되다、나、우리、년、때、같다、잘、말、말하다、생각하다、때문、네。
  - 네は第4章第4節の模範例（`네, 물을 마셔도 돼요.`）で使われているのに、語彙にありません。
  - 一方で、강아지（14028位）、가위（6172位）は収録されています。
- **末尾配置**：
  - 同形異義語がある語は順位を付けない規則（`wordbook-sources.md:6`）のため、먹다・쓰다・밤などが、順位34841位の여덟より後ろに並びます。
  - nikl.txtをバイト列で照合した結果は次のとおりです。
    - **照合済み**：먹다02＝70位（語釈「밥을 ~」）、쓰다01＝169位（語釈「글씨를 ~」）、밤01＝276位（語釈「어두운 …」）
    - **推定**：타다02＝260位は「乗る」と思われますが、語釈は照合できていません。
  - このように、語釈の欄を使えば同形異義語の語義は判別できます。
- **修正案**：
  1. 語釈の欄を使って、同形異義語を手作業で語義照合する。
  2. 最上位の語を追加する。
  3. 意図的に除外する語がある場合は、その規則を画面と文書に書く。
