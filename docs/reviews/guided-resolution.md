# ガイド学習と単語帳のレビュー対応

2026-11-12の修正前の[Opus独立レビュー](guided-opus.md)について、指摘の採否と範囲を整理する。元の834項目・順位付き706項目は当時の記録である。現在は849項目、順位付き736項目。動線の受入範囲は[完了・再挑戦・音声案内の受入](honest-flow-acceptance.md)、教材と語彙の個別照合範囲は[教材・単語帳の受入](opus-content-acceptance.md)を参照する。

## P1

| 指摘                                | 対応と判断                                                                                                                                                                               |
| ----------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| P1-1 day43/44の完了不能             | 指摘を受け、未実施を残した終了を追加。重要な音声は未確認のままなので完全完了の条件から除外せず、未実施を得点化しない。完全完了できない状態は残るが、虚偽の記録なしに次へ進み再開できる。 |
| P1-2 day47で二つの声がない場合      | 指摘を受け、節の主題を予定の聞取りにし、別の声による比較を拡張練習とした。実績がない場合も未実施を残して終了できる。                                                                     |
| P1-3 実施できない必須チェック       | 録音比較を対象節の必須項目から外し、聴取などができなければチェックを付けず部分終了できる。未実施を技能実績に加算しない。                                                                 |
| P1-4 末尾の主ボタンが完了を飛ばす   | 条件を満たす場合は「完了して次へ」で完了と復習登録を行う。満たさない場合は部分終了として保存する。                                                                                       |
| P1-5 基本語の欠落と同形異義語の順位 | 指摘された基本語を追加し、個別の語義照合で対応できた同形異義語に順位を付けた。全項目の語義照合を意味しない。詳細は[出典記録](../research/wordbook-sources.md)。                          |

部分終了は`partiallyFinishedLessons`に保存し、目次に「未実施を残して終了」と表示する。回答やfalseの自己確認は変更しない。後に条件を満たして完全完了すると部分終了を解除する。旧バックアップは空の部分終了一覧を補完する。

## P2と疑義

- 再挑戦：以前は答え合わせで正解が表示されていたため、その後を「答え閲覧後」と記録すること自体は事実に合っていた。今回は不正解時に正解と解説を伏せ、閲覧前に再挑戦できるよう改善した。
- 音声がない場合：利用できない聴解を未実施のまま部分終了できる。発音画面の折りたたみから声の選択・試聴と案内を利用できる。実音声の品質は未確認。
- 発音分類：新しい発音技能は追加せず、既存の5技能を維持する。発話の自己評価に発音の観察を含むと明示し、技能の認定とはしない。入力の自己評価は結果で別に数える。
- 必須チェックと課題文：自己確認を模範例の外へ移し、対象節の課題や到達目標を個別に見直した。day49の日本語を含む`model`は作文の案内で、発話用の`speakingModel`は韓国語である。
- 単語帳：節内語彙の音声、同じ節の実例による文法音声、語義を分けた감다と일の扱いを整えた。出典と順位の時代的な制約は[出典記録](../research/wordbook-sources.md)に記載する。
- 互換性：設定ページや画面上の出典・メモは撤去したが、旧データの`notes`と出典位置は互換性のため保持する。

表示密度、復習アイコン、章・既習・教材外による絞り込み、テーマ分類、全項目の例文などは設計提案として残し、未実装を確定不具合とは判定しない。合成音声のスラッシュ読みや実音声の品質は未実聴の疑義である。新たな音声の制作や固定録音の収録は行っていない。最新の自動検証は[検証記録](../archive/VERIFICATION-guided-wordbook.md)を参照し、母語話者による全文照合と実機確認とは区別する。
