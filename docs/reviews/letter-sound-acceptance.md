# 字母音声ガイドの濃音注記修正の限定受入

- 実施日：2026-11-12
- 対象：`docs/reviews/soundguide-polish.md`のP2に対する`letterSoundData.ts`・単体テストの修正、および`docs/research/letter-sounds.md`。
- 結果：P2の解消を確認。今回の限定範囲に追加指摘なし。実装コードの変更・コミットは行っていない。

## 言語的照合

国立国語院の[オンライン相談回答](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=73&pageIndex=1&qna_seq=329918)を直接取得し、標準発音法第14項の説明を確認した。終声ㅄに母音で始まる語尾が続く場合、ㅅを濃音[ㅆ]にして次の音節の初声へ移すと説明し、없어を[업ː써]と示している。

修正後の없어요の注記は「母音で始まる語尾の前ではㅅが濃音ㅆになって次の音節へ移る：[업써요]」で、濃音化と連音を明示している。없어요への適用と長音記号を省略した説明であることを調査記録も明記しており、出典の説明と整合する。この照合は当該規則と注記だけを対象とし、全見本や全教材の言語的確認を意味しない。

## 動作・コード確認

- データの`text`は実表記の`없어요`を維持し、発音表記`[업써요]`は`note`に分離されている。
- `LetterSoundGuide.tsx`の再生ボタンは`play(sample.text)`を呼び、`audio.play(text)`へ渡す。発音説明をTTSへ渡す経路はないことを静的に確認した。
- 追加された単体テストは`ㅄ`・`없어요`・`濃音ㅆ`・`[업써요]`を確認する。`mise run test -- src/features/learning/letterSoundData.test.ts`は1ファイル5件成功した。
- ガイドの「端末の合成音声は実聴未確認」「微細な音の違いの採点には使いません」の表示を確認した。ガイドに採点処理はなく、確認済み音声を要求する既存の判定も`src/domain/progress.ts`と`src/features/assessment/results.ts`で維持されていることを静的に確認した。

## 未確認・対象外

実音声の実聴、録音品質、iPhone・Windows実機、全見本の母語話者照合は未確認。今回ブラウザー操作や全回帰テストは実施していない。全56課の教材改訂、他担当の変更、および既存の広範なUIレビューは今回の対象外とする。
