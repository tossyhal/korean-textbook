# 手動復習の受入レビュー

2026-11-12。対象は`src/App.tsx`の手動復習登録・解除、`src/features/review/manual.ts`とそのテスト、`tests/browser/manual-review.spec.ts`。仕様、AGENTS.md、`docs/reviews/manual-review.md`と照合した。実装コードは変更していない。

## 判定

**受入。修正を要する不具合の指摘なし。**

- 語彙・文法参照、各課の語彙、問題解説から安定した教材IDで追加・解除する。正答した問題も登録できる。
- 追加helperは同じIDがあれば既存配列を返すため、日付・間隔・結果を無断でリセットせず重複登録しない。解除は対象IDの予定だけを削除し、再登録は当日・間隔0の予定を作る。
- `ReviewControl`は進捗を展開して`reviews`だけを更新する。回答、下書き、答え閲覧済みID、`reviewHistory`は保持する。解除後の再登録でも答え閲覧済み状態を維持するため、自力想起へすり替わらない。当日に復習済みの項目は既存の日次履歴に従って同日の再実施対象から除外され、翌日以降に再開する。
- 既存の誤答時の問題・タグ登録は維持され、手動で追加したIDとも重複しない。復習画面の日次20件上限と閲覧後の自力想起禁止を変更していない。
- 新規予定は既存のバックアップ用参照ID集合に含まれる。正答問題と語彙の登録、再読み込み、JSON書き出し・取り込み、解除後の回答履歴保持をChromiumで確認した。
- ホームの滞留案内は期限到来21件以上で新出を控えるよう促す。課へのリンク・開始処理にロックを追加していない。
