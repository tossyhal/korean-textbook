# 手動復習の動作確認

2026-11-12。語彙・文法参照、各課の語彙、問題の解説から復習予定を追加・解除できる。登録済みの予定は追加操作で変更せず、解除は予定だけを削除する。再追加も可能。

- Vitest：登録の重複防止、予定維持、解除と再登録を確認。
- Chromiumの自動テスト：正答した問題と語彙を登録し、再読み込みとJSONバックアップの書き出し・読み込み後、語彙を解除して回答履歴と復習閲覧履歴を保持することを確認。
- 既存のChromium自動テスト：復習の閲覧状態と日次20件上限を再読み込み後も保持することを確認。
- 型検査、lint、全Vitest、ビルドは成功。ビルドには既存の大きなチャンクに関する警告がある。

言語的照合や音声の内容確認は今回の対象外。実機確認は行っていない。
