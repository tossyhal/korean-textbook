# 読書画面・文字音声レビュー

2026-11-12、feature/readable-lessons-audioの共有作業ツリーを読み取りレビュー。App、学習CSS、KoreanText、音声Provider／SpeakableText、LetterSoundGuide、発音リファレンスが対象。教材著者の本文編集と、並行修正中の旧UIテスト期待値は担当外。アプリソースの変更・コミット・pushは行っていない。

## 結論

確定P2が3件ある。P0・P1は確認していない。以下を修正してから受け入れる。

### P2：スクロール中にナビゲーションの開閉が使えない

- 場所：src/features/learning/style.css:417、src/App.tsx:707。
- トグルは通常フローの先頭にあり、stickyの左ナビと一緒には残らない。1280×900で本文を1000pxスクロールすると、左ナビはtop=16pxに残るが、開閉ボタンはtop=-910.36px、bottom=-866.36pxになる。
- 閉状態でもトグルは同じ通常フローなので、本文を読んでいる位置から再表示できない。長い本文で先頭まで戻る必要があり、常時開閉可能という要求を満たさない。
- 開状態・閉状態ともに、本文を覆わない位置へトグルを常時残す。画面上部だけでなく、本文中・末尾でビューポート内にありキーボードから操作できることを確認する。

### P2：再生Promiseの拒否で再生中状態と未処理エラーが残る

- 場所：src/features/audio/SpeakableText.tsx:65。
- player.playとawait pendingをtry/catchしていない。falseの解決は表示できるが、拒否ではsetPlaying(false)、activeの解除、近傍エラー表示まで到達しない。
- 実ブラウザで韓国語voiceのモックと、例外を投げるSpeechSynthesisUtteranceコンストラクターを注入して文字をクリックした。unhandledrejectionに`Error: review constructor failure`、ラベルに`가を聞く（再生中、停止）`が残り、.speakable-errorは0件だった。通常の端末発生頻度を示す検証ではなく、明示された拒否時処理の契約を確かめる故障注入である。
- 呼び出しとawaitを捕捉し、現在のrequestだけ失敗表示と状態解除を行う。外部停止・別文字再生・離脱後の古い拒否は失敗表示や完了コールバックを発生させない。正常完了、拒否、停止後の遅延拒否を分けて検証する。

### P2：本文の終声字母が初声の見本へ置き換わる

- 場所：src/components/KoreanText.tsx:7、src/features/audio/SpeakableText.tsx:25、src/App.tsx:796。
- 本文の全文字母に文脈なしでsoundExampleを適用するため、第3節の「강の終声ㅇは鼻に抜ける音」のㅇが아、「終声のㄱ・ㄷ・ㅂ」が가・다・바になる。ブラウザのラベルも`ㅇの音を아で聞く`、`ㄱの音を가で聞く`だった。終声を説明する位置のクリックで初声の例が鳴り、特にㅇは鼻音の見本にならない。
- LetterSoundGuideの明示サンプルは악・안・앋・알・암・압・앙を維持しており、こちらは対象文脈を保っている。ㅄも없다に割り当てており、裸の字母のTTSは回避している。問題は本文の汎用自動変換である。
- 字母クリックを維持する場合は、本文の位置・役割に対応するsampleTextを渡せる契約にする。単なる「この文字を含む一般音節の例」とするなら、その意味を明示し、終声見本と受け取る位置には適用しない。本文字母を一律に初声化する実装のまま受け入れない。

- 選択中の段階、上下キー・Home・End、Escapeによる収納とトグルへのフォーカス、開閉設定の保存と再読み込み後の段階復元は、対象ブラウザテストで通過した。
- SpeakableTextの外部停止通知とrequest無効化、別文字再生・画面離脱時の停止は実装上整っており、対象ブラウザテストでも偽エラーなしを確認した。完了コールバックは成功解決後に呼ぶ配置である。Promise拒否の例外は上記指摘のとおり。
- KoreanTextは既定で非操作表示で、本文paragraphにだけplayableを渡している。問題選択肢などへ一律にボタンを入れる変更ではない。対象の発音ページでbutton内buttonは0件。

- TTS成功時・通常時に繰り返していた確認状態メッセージが削除され、再生不能時の近傍メッセージは残る。実音声の確認状態やデータの正確性を変更したものとは評価していない。
