# 続きから学ぶ動線の修正

先取りで複数課に保存位置があると、従来は課番号が最も早い未完了課を選び、最後に学んだ課に戻れなかった。課を開いたときと課内位置の更新時に最後の課IDを保存し、未完了ならそこを優先する。完了済みなら後続の未完了課を選び、後続にない場合は他の未完了課、全課完了の場合は最後の課に戻る。診断や設定への遷移では更新しない。

既存データに最後の課IDがない場合はnullを補完し、従来どおり保存位置のある未完了課から選ぶ。JSONにはIDを含め、存在しない課への参照を拒否する。位置と下書きは既存の保存方式を維持する。
