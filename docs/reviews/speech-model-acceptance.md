# 録音比較の発話手本レビュー

2026-11-12。未コミットの発話手本分離を独立レビューした。コード変更・コミットは行っていない。ホームとバックアップの並行変更は対象外。

## 結果

発話手本の選択とデータについて、修正が必要な不具合は見つからなかった。

- `production.speakingModel`は空文字を許さない省略可能フィールドで、既存の`model`・`prompt`・`rubric`のみの形式を維持している。
- `productionSpeakingModel`は指定された発話例を優先し、省略時に従来の`model`へ戻る。`App.tsx`の作文・発話欄から`Recorder`へこの結果が渡る。
- 第1〜7週で分離した13課に取り違えはなかった。第21課は既存の末尾2文を発話用に選び、他12課は表示用模範例の「発話：」以降と一致した。
- 最終確認時点では第8週7課にも発話例があり、全56課中20課の発話例が表示用模範例の該当部分と一致した。日本語の作文・発話ラベルや作文部分を録音比較へ渡さない。
- `docs/USAGE.md`のフィールド説明は実装と一致し、合成音声の品質と実機確認を未確認と記載している。課末の音声状態も確認済みへ変更されていない。

## 既存箇所の観察

`src/features/recording/index.tsx`の録音比較欄は、手本が端末の合成音声で内容未確認であることを、その場では表示していない。課末の音声状態と利用手引きには未確認の記載がある。今回の差分による退行ではないが、録音手本の近くでも分かるよう案内する改善候補として親と実装担当へ共有した。
