### 2. 日本語の意味回答と韓国語の許容形に自然な正答の取りこぼしがある

`shared.ts`の`listening()`は`answers: [answer]`を生成する。採点はNFC・空白・末尾句読点の正規化後の文字列一致であり、意味一致は行わない。したがって次の妥当な回答がデータ上は不正解になる。

| 問題ID                                           | 現在の正答   | 取りこぼす回答例           |
| ------------------------------------------------ | ------------ | -------------------------- |
| `day-04-exit-listen-3`「音声の人物は先生ですか」 | 先生ではない | 先生ではありません、いいえ |
| `day-04-ex-listen-1`「職業は」                   | 医師         | 医者                       |
| `day-07-exit-listen-1`「動作は何ですか」         | 食べる       | 食べます、ご飯を食べる     |
| `day-07-exit-listen-4`「移動先はどこですか」     | 家           | 家へ、家に                 |
| `day-06-ex-11`「水を飲みます」                   | 물을 마셔요  | 물을 마시어요              |

聴解の意味回答は、既習語から選ぶ選択問題にするのが範囲を狭く保てる。入力のままなら回答単位・言語を明示し、自然な表記を許容解へ追加する。韓国語の固定文は指定助詞・語順・縮約の有無まで必要に応じて限定する。上の未縮約形は同じDay6本文・`ex-04`で認めているため、`ex-11`だけ除外する理由はない。単語活用の許容解修正が文全体の設問にも行き渡ったか確認すること。

### 3. Day5出口に韓国語の理解を測らない設問がある

`day-05-exit-03`は「本は家にあるが、かばんはない。ない物は何ですか」で、韓国語が一字もない。韓国語を読めなくても日本語だけで正答でき、`없어요`の理解を評価できない。問題の説明欄で韓国語を補っても、回答時の測定対象は変わらない。

`day-05-exit-01`も「かばんは学校、本は家にあります」と全情報を日本語で先に示すため、韓国語の読み取りを弱める。両問は既習語だけの新しい韓国語の短文を提示し、物・場所・不在を日本語の選択肢から答える問題へ置換する。

## 軽微な編集事項

- Day4「話題と主語」の追記は「誰が医師か」を話題にしているのに`의사가 선생님이에요`（医師が先生です）を示す。何を尋ねた答えなのかがずれる。「誰が先生か」にそろえるなどして、主語を選ぶ文脈を明瞭にする。出口側は「誰が先生か」になっている。
