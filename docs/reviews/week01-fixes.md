# 第1週教材の修正記録

2026-11-12。対象は第1週の教材データ。UI・音声機能の修正は別担当。

- Day1〜3に母音の字形と位置、子音の音節見本、複合母音の構成と発音の幅、単一終声の代表音と口舌の手掛かりを追加。Day2の音声運用を問う出口問題とDay3の既出演習と同じ出口問題を置換。
- Day4に話題と主語の文脈、Day6に移動先の에と세 시の構成を追加。存在の있다の品詞を形容詞に修正。助詞と数詞などを語彙に追加し、本文に主要語と丸ごと表現の注釈を補った。
- 分かち書きを残すstandard正規化で文末句点を許容。마시어요・공부하여요も丁寧形の許容解とした。
- Day4〜6の出口は条件や情報抽出を含む課題に置換。Day7は自動採点20問を読字・入力・読解・聴解へ配分し、作文・発話を自己評価として別にした。例文に試験の正解文を先に提示しない。
- 音声と全課の言語状態はunverifiedを維持。出典のcheckedは資料で実際に確認した事項のみを示し、自作教材全文の照合を意味しない。

## 検証と残課題

- `pnpm run content:check -- --partial`、`pnpm run typecheck`、担当範囲のoxfmt・oxlintを実行。
- 自作例文・全問題・許容解の母語話者による個別照合、口舌説明の一次資料による個別照合、端末音声、実機操作は未確認。語彙・注釈の網羅と初見性も独立した再レビューが必要。
- UI側の聴解原文の開閉、弱点リンク、自己評価の保存、録音と音声の排他は別担当の確認を要する。
