# 第1週レビュー

2026-11-12。対象は`src/content/lessons/week01`、`src/App.tsx`、音声・録音実装。AGENTS.md、仕様全文、ASSESSMENT.md、week01の調査記録を読んで静的に確認した。ブラウザ確認は親担当。言語照合とソフトウェアの動作確認を混同しない。

結論：第2週制作へ進む受け入れ基準は未達。次の指摘を修正して再レビューする。全課の`languageStatus/audioStatus: unverified`は現状に即している。

## 修正が必要な事項

### P1：出口・週末評価が既出の答えの再生になっている

Day4の出口聴解`학생이 아니에요`は同課練習、Day5の`책이 없어요`も同課練習、Day6の`물을 마셔요`も同課練習と同一。技能を変えても「練習とは別の問題」という表示と仕様の独立性を満たさない。Day3出口の국물の発音も直前の練習と同じ。

Day7は강の終声、국물の発音、선생님の이에요、의사の예요、가다/마시다の活用、물の을などが既出問題と実質同一。出口も밥の終声、医師の否定、場所の区別が既出で、聴解`집에서 공부해요`は同じページの例文として先に提示される。初見の短文読解はない。例文6件に増やすだけでは総合評価にならない。

修正案：学習済み語を使う新しい配置・話者の立場・短い会話を設け、表面の再現でなく情報の読み取りと文の生成を問う。Day7は試験前の例文で正解を見せず、読字・入力・短文読解・短い聴解を独立した設問へ割り当てる。技能を変えただけの同一原文も重複検査対象にする。

### P1：自然な固定解を誤答にする

`shared.ts:33,123`で分かち書き問題を`exact`にしている一方、正解文には句点がない。そのため本文と同じ`저는 의사예요.`、`책이 없어요.`、`물을 마셔요.`を入力すると誤答となる。空白を評価しながら末尾句読点を許容する方針か、句点あり/なし双方の許容解が必要。

Day6練習`마시다の丁寧形`、Day7同問は`마셔요`だけで、未縮約の`마시어요`を誤答にする。Day6練習`공부하다の丁寧形`も`공부하여요`などの扱いを見直す。縮約を評価するなら問題文を「縮約した形」に限定し、一般的な丁寧形を問うなら自然な許容形を用意する。

Day5出口「本は学校にあります」「私は家にいます」は助詞や主語省略を限定せず`책이 학교에 있어요`、`저는 집에 있어요`のみを採点するため、`책은 학교에 있어요`や文脈に合う省略を排除する。Day7「本はここにあります」も同様。指定部品を示す固定組立問題にするか、自由度を残すなら複数解/自己評価へ変更する。

### P1：字母・終声の本文が自力で読むための説明を欠く

Day1は基本母音10個を列挙するがㅣの口舌説明などがなく、例は가/나/다/마/아/오に偏る。Day2は11母音を列挙するがㅙ/ㅚ/ㅞ/ㅢ等の構成・読み・入力の説明と段階練習が足りず、未説明の組み合わせを出口で問う。Day3は「代表音は7つ」とだけ示し、どの終声字がどの代表音になるかの対応がない。初学者は낫など未知のパッチムを読めない。終声ㄹ等の口舌説明もない。

修正案：各字母/代表終声について、音節見本、口舌の手掛かり、誤り、組立練習を対応させる。終声の字形→代表音の最小限の対応表と既習字母による例を置く。未確認TTSを聞けば説明を補えるという前提にしない。Day2のㅟは単母音だけでなく許容される二重母音の発音も説明する。

### P1：新出語の注釈・既習前提が揃っていない

語彙データには助詞은/는、이/가、에、에서、을/를が未登録。丸ごと表現네/안녕하세요/반갑습니다、한글、세/시等も語彙または明示的な表現としての管理がない。Day6の세 시は一度注記するだけで、本文から時刻の語構成を理解できないまま出口で`세 시에`を問う。LessonPageには課の語彙一覧自体がなく、各例の新出語の意味・品詞・辞書形は別リファレンスを探索しないと確認できない。

Day6は所在の에と時点の에しか説明せず、移動先の에を使う`학교에 가요`と`집에 와요`を出す。新用法として説明するか例を範囲に合わせる。Day4は「話題と主語を見分ける」を目標にする一方、肯定文で의사が主語となる対照文脈などがなく、日本語訳との機械対応を否定する説明だけで文脈選択を練習できない。

### P2：있다の品詞が出典と異なる

`day05.ts:141`は「動詞」。同課の存在・所在・所有の語義に対応する、リンク先の있다²は「形容詞」。語彙データを修正する。있다には別の語義・品詞があるため、単に全用法を動詞とまとめない。

### P1：聴解の「聞く→原文確認→隠して再聴」の動線がない

QuestionViewは最初に原文を隠す点と、再生完了成功後に回答を許す点は満たす。しかし意味を答える聴解の解答後も`q.audio.text`は表示されず、たとえばDay4練習では「医師／의사は医師です」だけで原文`저는 의사예요`を確認できない。例文・会話の原文と訳は常に表示され、隠す操作がない。問題音声には通常/ゆっくりや繰り返しの操作もない。

修正案：聴解は解答後に原文・訳を開閉できるようにし、原文閲覧を記録する。短区間の書き取り・復唱・再び隠して再聴へつなぐ。例文/会話にも原文・訳の表示切替を用意する。

### P2：弱点リンクが該当本文へ戻らない

`App.tsx:403-411`は`grammar-*`タグをすべて現在課の`section-0`へスクロールする。Day6の場所助詞誤答でも語幹の説明へ、Day7の全誤答でも試験の取り組み方へ戻る。正しい前提課/節への参照をデータに持たせる。

### P2：作文・発話の自己評価が保存されず技能別結果にも反映されない

`App.tsx:434`のselfCheckedはローカルstateで、再読み込みや課の移動で消える。技能別summaryは出口の固定解だけを集計し、productionに取り組んでも発話が0/0のまま。作文・発話それぞれの実施・自己評価を進捗に保存し、自由作文を固定解の正答数へ混ぜず別指標として表示する。Day7模範例には課題が求める「物の場所」の文もなく、ルーブリックにもその確認がない。

### P2：録音再生と手本音声の排他が片方向しかない

Recorderの録音開始とcompareは既存音声を止めるが、`recording/index.tsx:103`のnative audio再生は共通AudioEngineに登録されない。録音再生中に例文の再生を押せば両方が鳴り、録音中にも例文/compareを再生できる。音源が録音に入り、比較を妨げる。native audioのonPlay、共通再生開始、録音状態の間で排他/停止を共有する。画面離脱時のdispose、遅延許可後のtrack停止、Object URLの破棄はコード上実装されている。

## 今回実際に読んだ一次資料

- [国立国語院・韓国語基礎辞典있다²](https://krdict.korean.go.kr/jpn/dicSearch/SearchView?ParaWordNo=68797)：形容詞、存在・所在・所有の語義と`1이 2에 있다`の文型。品詞誤りを確認した。音声は聞いていない。
- [国立国語院オンラインガナダ・에요/예요](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=1&qna_seq=306190)：母音終わりの名詞で未縮約이에요と縮約예요が使えること、아니에요の形を確認。Day4のこの説明と両形の許容は妥当。
- [国立国語院・韓国語正書法](https://korean.go.kr/kornorms/regltn/regltnView.do)：第36項のㅣ+-어の本言/縮約形の扱いを確認。마시어요を一律排除する採点には根拠がないと判断。個別の自作例文の自然さ全部を照合したわけではない。
- [国立国語院・標準発音法第3〜5項](https://www.korean.go.kr/kornorms/m/m_regltn.do?regltn_code=0002)：ㅚ/ㅟの二重母音発音の許容、ㅐ/ㅔの話者差の説明を確認。Day2はㅟの説明に許容範囲を補える。
