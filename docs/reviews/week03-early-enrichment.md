# 第3週前半の語彙補強

追加した辞書形は第15課11語、第16課6語、第17課9語の計26語。既存の第16課6語と第17課1語を含めると、それぞれ11・12・10語。第8課の本文に既出だった좋아하다も初出課へ登録した。活用形は別語として数えない。
