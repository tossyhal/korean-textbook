# 第7週独立レビュー

2026-11-12。第43〜49課、共通生成処理、評価テスト、音声の未実施条件を確認した。コードは変更していない。以下の修正後に受け入れを再確認する。

## 指摘

### P1 W7-01：音声と設問の行動が一致しない

- 対象：`day49.ts:223`、`day-49-exit-listen-10`。
- 音声は`오늘은 비가 와서 차를 사요.`で、雨を理由にお茶または車を買う内容。一方、質問は「家にいる理由は？」となり、家にいるという事実は聞けない。雨という語だけで想定解を選べても、設問の意味理解は評価できない。
- 最小修正：質問を音声の行動に合わせるか、音声を実際に家にいる内容へ直す。後者は初見音声と既習語彙の条件も再確認する。

### P2 W7-02：連音の説明がㅎを含む一般則になっている

- 対象：`day44.ts:17`、`section-1`／`grammar-linking-sounds`。
- 「母音で始まる助詞や語尾が続くと、単一パッチムは次の音節の頭へ移って発音します」は、単一パッチムㅎにも適用できる説明。標準発音法第12項4では母音始まりの語尾・接尾辞の前のㅎは脱落し、`놓아[노아]`などになる。第13項の例`옷이[오시]`と`꽃을[꼬츨]`自体は正しい。
- 最小修正：ここで扱うㅅ・ㅊなどの連音へ説明範囲を限定し、ㅎには脱落など別の規則があると短く明示する。終声ㅇなども含め「単一パッチムならすべて移る」と読める表現を避ける。
- 根拠：[国立国語院・第12項4の説明](https://korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&qna_seq=317352)、[第13項と第23項](https://korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=98&pageIndex=1&qna_seq=323814)を実読。

### P2 W7-03：第46〜48課の想起・産出課題が共通の予定作文になっている

- 対象：`late-shared.ts:44`と`:64`、第46〜48課の`recall`／`production`。
- 3課とも同じ想起2問、同じ予定の作文・発話、同じモデルと観点になる。作文と発話は分かれているが、第46課の会話書取、第47課の別音声への転移、第48課の初見情報抽出に応じた振り返りや産出へつながらない。`CONTENT_AUTHORING.md`の各課固有の想起・production条件を満たさない。
- 最小修正：共通関数のデフォルトを各課で上書きする。たとえば第46課は聞いた予定をメモして別の相手へ伝える、第47課は別音声で取った内容を言い換えて確認する、第48課は初見の会話から得た時・場所・行動を短く報告する。各課で作文と発話のモデル・観点を分け、音声不可なら未実施を保つ。

### P2 W7-04：第46〜49課の言語出典が教材内容と対応しない

- 対象：`late-shared.ts:24`、`day49.ts`の`sources`、`docs/research/week07-late.md`。
- 唯一の言語出典は`제일`の副詞義だが、第46〜49課の本文・例・問題に제일は登場しない。出典の記載は実読内容を限定しており虚偽ではないものの、この4課で教える疑問語や会話理解の言語的照合の根拠にはならない。
- 最小修正：実際に使う疑問語や時・場所・順序の表現について関連する一次資料を開き、確認した項目を各課と研究記録へ対応付ける。全文の自然さや合成音声の確認へ範囲を広げて報告しない。
- 根拠：[国立国語院・제일](https://krdict.korean.go.kr/eng/dicSearch/SearchView?ParaWordNo=92032)を実読し、複数の中で最もという副詞の項目であることを確認。

## 確認できた事項

- 第43課は母音の口・舌、激音の息、濃音の緊張、平音と日本語の清濁の違いを記載。ㅐとㅔを綴りだけで判定できない話者差の説明は、[国立国語院の解説](https://www.korean.go.kr/front/mcfaq/mcfaqView.do?mcfaq_seq=8415&mn_id=217&pageIndex=4)と整合する。字母名のTTSを手本にせず、語の音声を用いる。
- 第44課の7終声、국물[궁물]・먹는[멍는]、국밥[국빱]の条件と例は[標準発音法第8・18項](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=216&pageIndex=2&qna_seq=313220)および第23項と整合。元の表記と角括弧の発音表記を分け、TTSへ発音表記を重ねていない。
- 第43・44課の重要音声は`requiresVerifiedAudio: true`かつ`unverified`。画面・集計とも未実施を保つ実装とテストがある。第45課以降の通常の意味聴解をこれとは分けている。
- 第45課は疑問語、数と単位、音声問題と短い書取を備える。第46課は意味聴解と短区間書取、第48課は原文をpromptへ出さない会話音声を備える。
- 第47課には実教材の`voiceTransfer.sameSentence`／`newSentence`がある。異なるURIを明示選択し、3回の再生終了と自己確認が記録条件。0声・1声、中断、エラーは未実施のままで、他の学習を続けられる。異なるURIを実在の別話者の保証としない。
- 第49課は24問（聴解12、読解8、入力4）と自由な作文・発話を分け、誤答タグから本文へ戻る参照がある。一般的な既習語の再使用そのものは欠陥として扱っていない。
- 固定書取は文末句点を許し、語間の空白を消さない。自由な作文・発話を単一文字列で自動採点しない。
