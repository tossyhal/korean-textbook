## 残る指摘

### P2 A8-01：W8-02の復習先不足が追加問題で再発している

`linkReview()`は問題文と解説の正規表現一致で文法を追加するため、実際に解くために必要な文法を取りこぼす。例えば以下は実行時にも当該課の方針タグしか持たない。

| 問題           | 現在の唯一の参照                      | 必要な説明                                                                |
| -------------- | ------------------------------------- | ------------------------------------------------------------------------- |
| day-53-ex-5    | 第53課section-0「品と数量を指定する」 | 時を表す에と필요해요。少なくとも同課section-1「必要な時間を伝える」へ戻す |
| day-53-ex-6    | 第53課section-0                       | 追加の도と괜찮아요。同課section-2または既習の追加・限定の説明             |
| day-54-ex-5    | 第54課section-0「例をまねる」         | 듣다→들어요のㄷ不規則、第20課grammar-d-irregular／section-1               |
| day-54-ex-6・7 | 第54課section-0                       | 언제／어디에서の疑問語、第12課grammar-questionsなど                       |

第55課ex-7は正解に오면があるが、正規表現の入力にanswersが含まれず、問題文にも解説にも一致する文字列がない。タグとreviewTargetsを実際の設問ごとに確認する必要がある。当該課の統合方針タグを併記すること自体は問題ではない。

### P2 A8-02：動作場所の追加タグが所在の説明へ飛ぶ

`review-links.ts`は「動作の場所」等から`grammar-location`を追加する。このIDの初出は第5課section-1で、本文は存在場所の에を説明し、에서は「後の課では…比べます」と予告するだけ。第55課ex-5と第56課ex-08は、에서の組み立てを誤っても、その説明へ戻らない。

第18課`grammar-location-review`／section-2には所在・到着点の에と動作場所の에서の具体的対照がある。第6課section-1にも実説明がある。初出定義を変えず、実際に説明がある既存参照へ結び直す。

### P2 A8-03：W8-06の補充に同一演習が含まれる

第53課ex-1と追加ex-9はともに`물 한 병 주세요.`を出し、同じ「水一本」の数量理解を選択式で問う。ex-1の選択肢「一本／二本／一個」とex-9の「水一本／水二本／お茶一本」は、同じ原文の同じ数量を再び答える構成である。通常課12問のうち1問を同内容で満たしており、量だけを満たす重複問題を避ける仕様に達しない。

第55課ex-2と追加ex-12も「학교에서 책을 읽어요.／도서관에서 책을 읽어요.」の場所を選ぶ同型で、場所名のみを替える補充になっている。条件を受けた返答、数と時の食い違いの修正、履歴から選んだ文法の再適用など、課固有の別の判断へ置き換える。

その他の追加選択問題は、時・人物・理由・条件などの取り違えを選択肢にしており、韓国語として成立しないダミーを選ばせる問題は見つからなかった。ただし「から分かる内容は？」が多く、何を確かめるかを「誰と／どこで／なぜ」等へ具体化すると目的が明確になる。

### P2 A8-04：新規入力で未縮約形を不正解にする

第53課ex-5は「明日の午前に必要です」を내일 오전에から入力する指定で、縮約形には限定していない。許容解は`내일 오전에 필요해요`だけで、未縮約の`내일 오전에 필요하여요.`を`gradeAnswer`へ渡すと`incorrect`になる。同じ追加問題群の第55課ex-5では`공부하여요`を許容している。

필요하여요を許容するか、縮約形を問う意図を問題文に明示する。また、第53〜55課の追加固定入力は使用語の指定はあるが해요体の指定が省かれている。複数の丁寧さや言い換えを無制限に列挙する代わりに、各設問で使用語・해요体・助詞・語順のうち採点に必要な条件を明示する。
