# 第8週の統合・語彙確認

第8週を教材一覧へ接続し、全56課の構造と参照をstrict検証した。第8週の本文、例文、会話、練習、出口テスト、ロールプレイと第56課の固定採点に出る語を既存語彙と照合し、未登録だった21項目を追加した。うち14項目は先に現れる第1、20、26、29、30、32、34、39課へ登録し、7項目は第50〜53課へ登録した。사과は「謝罪」と「りんご」の同形異義語であり、別の意味とIDを持つ。あいさつと問いかけの定型表現は表現として登録した。

網羅確認は手作業であり、未登録語の残数は未確定。特に過去の全教材における全語形・複合表現の初出と、第8週の新出語の全数について独立した言語レビューが必要。第56課の固定入力に使う지금、만들다等は既出課への登録を確認したが、全問の語彙習得を保証するものではない。

構造検証、単体テスト、型検査、lint、担当ファイルのformat検査、buildを実行した。母語話者による全数照合、実音声の確認、実機確認は実施していない。語彙の追加は言語確認済みを意味しない。
