## 指摘

### P2 W8-01：第56課の過去形入力で既習の未縮約形を誤答にする

- 対象：`day56.ts`、`day-56-exit-input-2`。
- 問題は보다を過去の해요体にする指定で、縮約形に限定していない。しかし許容解は`어제 영화를 봤어요`だけ。第10課の復習問題でも許容している`보았어요`が不正解になる。
- 再現：`gradeAnswer(q, "어제 영화를 봤어요.")`は`correct`、`gradeAnswer(q, "어제 영화를 보았어요.")`は`incorrect`。
- 最小修正：`어제 영화를 보았어요`を許容解へ追加し、この問題で未縮約形・句点を認める回帰確認を置く。

### P2 W8-02：弱点タグが既習事項の説明へ戻らない

- 対象：第50〜52課の生成元`week07/late-shared.ts`、第53〜55課の`middle-shared.ts`、第56課のタグ上書き。
- 当該課の学習方針や課題名を新規文法として登録し、既習の文法問題にもそのIDだけを付けている。例えば`day-50-ex-input`の읽어요は「名詞を説明する部分を見つける」へ戻り、丁寧形の作り方へ戻らない。`day-51-ex-input`の過去活用も「日記の出来事を並べる」が参照先になる。
- 第56課では固定入力8問すべてが`grammar-w8-final-input`／`section-1`。`day-56-exit-input-3`の義務、同4の条件、同5の進行、同6の許可、同8の希望を間違えても、そこには各形の作り方がない。読解の連体形問題`day-56-exit-08`も連体形の説明へ戻れない。
- 最小修正：問題に実際に必要な既存IDを再参照する。義務は第23課`grammar-obligation`、条件は第24課`grammar-condition`、進行は第22課`grammar-progressive`、許可は第25課`grammar-permission`、希望は第13課`grammar-want`、連体形は第26課の対応IDなど。新たな同義文法を第8週初出として作らず、初出日・sectionId・定義を維持し、reviewTargetsにも必要な参照を入れる。第8週の「情報を統合する」という学習方針自体のタグを残すことは差し支えない。

### P2 W8-03：第50課の産出課題とモデル・観点が一致しない

- 対象：`day50.production`。
- 作文は「理由と順序を入れて」書く指定だが、モデルは時・場所・順序だけで理由がない。作文の3観点にも理由がなく、指定を満たさないモデルをそのまま達成例として扱う。モデルには別の発話予定もない。
- 最小修正：作文モデルへ既習形で理由を加え、理由と順序の両方を確認する観点にする。発話モデルも別の予定を明示するか、作文と発話を分けて示す。

### P2 W8-04：第53課の出口が先に出した同一原文を問う

- 最小修正：新しい短い依頼で、品・数量・受取時など複数の既習情報を結び付ける。単にりんごを別の品へ替えるだけでなく、時間条件などを統合して確認する。聞き返しの定型表現を産出し直す自己評価そのものは、ここでの指摘対象としない。

### P2 W8-05：第53〜55課の自己評価が一律2項目で、課題条件を確認できない

- 対象：`middle-shared.ts`の`self()`と、それを使う演習・出口。
- 全設問が「指定された情報を伝えたか」「模範と比べて不確かな箇所を確認したか」の2項目になる。ASSESSMENT.mdが求める3〜5項目の具体的な自己評価にならず、例えば`day-54-exit-2`の「好きな活動」「理由」「相手への質問」を個別に確かめられない。`day-53-exit-2`の品・数・時も一括である。
- 最小修正：設問ごとに具体的な3〜5観点を渡せるようにする。自由な事実・別の自然な言い方は認め、固定文字列の自動正誤へ変更しない。これは各ターンに1項目以上あるroleplayの構造検査とは別の問題である。

### P2 W8-06：通常の統合学習課にも試験例外を一律適用している

- 対象：`middle-shared.ts`の`lesson.lessonKind = "exam"`、第53〜55課。
- 第53課は演習3・出口3、第54・55課は演習4・出口3。仕様の通常課12演習・5出口の目安と、CONTENT_CONTRACT.mdの通常課検証を一律exam指定で外している。第53〜55課は条件付き対話・自由会話・弱点補強で、総合試験ではない。第54課には4ターンの対話があるが、第55課には対話もなく、同じ例外を適用する根拠が書かれていない。
- 最小修正：この3課を目的に応じた十分な演習・出口へ補い、通常課として検証する。対話ターン等を演習相当として設計するなら、数量例外の理由と各目標の評価対応を文書化し、単に検証を避ける指定にしない。

- 第56課の採点を左右する表現は、第1〜7週に説明または既習例があることを確認した。過去は第9課、予定は第10課、希望は第13課、順序・理由・対比は第15〜17課、進行・義務・条件・許可は第22〜25課、動詞連体形は第26課。温かいお茶は第16・39課、友達に電話するは第22課、散歩は第9課、注文の杯数と会計は第29課などに既出。第56課のために第50〜55課で初めて教える語・形を覚える必要がある重大な問題は見つからなかった。これはW8-01の許容形不足を解消するものではない。
